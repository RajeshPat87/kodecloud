# PART 1 — TERRAFORM AWS TASKS

## General workflow (every task)

```bash
cd /home/bob/terraform/<task-dir>
ls provider.tf 2>/dev/null || cp ../provider.tf .
cat main.tf 2>/dev/null || echo "empty"
terraform state list 2>/dev/null || echo "no state"
terraform init
terraform plan
terraform apply -auto-approve
terraform state show <resource>
terraform plan                         # must show No changes
```

## 1. VPC

### Variants

**Any IPv4 CIDR:**
```hcl
resource "aws_vpc" "<name>" {
  cidr_block = "10.0.0.0/16"
  tags = { Name = "<vpc-name>" }
}
```

**Exact CIDR:**
```hcl
resource "aws_vpc" "<name>" {
  cidr_block = "192.168.0.0/24"
  tags = { Name = "<vpc-name>" }
}
```

**Amazon-provided IPv6:**
```hcl
resource "aws_vpc" "<name>" {
  cidr_block                       = "10.0.0.0/16"
  assign_generated_ipv6_cidr_block = true
  tags = { Name = "<vpc-name>" }
}
```

**With variable:**
```hcl
# variables.tf
variable "KKE_vpc" {
  type    = string
  default = "xfusion-vpc"
}

# main.tf
resource "aws_vpc" "<name>" {
  cidr_block = "10.0.0.0/16"
  tags = { Name = var.KKE_vpc }
}
```

**Verify:**
```bash
terraform state show aws_vpc.<name> | grep -E "cidr_block|ipv6_cidr|tags|id"
aws --endpoint-url=http://aws:4566 ec2 describe-vpcs --region us-east-1 \
  --filters "Name=tag:Name,Values=<name>" \
  --query "Vpcs[].{ID:VpcId,CIDR:CidrBlock}"
```

## LocalStack drift fixes

```bash
# identify drifting attribute
terraform plan 2>&1 | grep "~"

# remove the drifting attribute from main.tf then
terraform apply -auto-approve
terraform plan                         # must show No changes
```

| Resource | Common drift | Fix |
|---|---|---|
| CloudWatch alarm | `tags` | remove `tags` block |
| Kinesis stream | `tags`, `stream_mode_details` | remove both |
| SNS topic | `tags` | remove `tags` block |
| OpenSearch | `tags`, `engine_version` | remove or match actual value |

## 2. Create container

```bash
# basic
sudo docker run -d --name <name> <image>:<tag>

# with port mapping
sudo docker run -d --name <name> -p <host-port>:<container-port> <image>:<tag>

# with volume mapping
sudo docker run -d --name <name> -v <host-path>:<container-path> <image>:<tag>

# with custom CMD (overwrites default)
sudo docker run -d --name <name> <image>:<tag> <command>

# all options
sudo docker run -d \
  --name <name> \
  -p 8081:80 \
  -v /var/www/html:/usr/local/apache2/htdocs \
  <image>:<tag> \
  sleep 1000
```

## 3. Container operations

```bash
# list running
sudo docker ps

# list all (including stopped)
sudo docker ps -a

# start stopped container
sudo docker start <name>

# stop running container
sudo docker stop <name>

# stop + remove
sudo docker rm -f <name>

# view logs
sudo docker logs <name>

# exec into container
sudo docker exec -it <name> /bin/bash
sudo docker exec -it <name> /bin/sh     # if bash unavailable

# run command inside container
sudo docker exec <name> ls -l /path/

# inspect full config
sudo docker inspect <name>

# inspect specific fields
sudo docker inspect <name> --format 'Image: {{.Config.Image}} | State: {{.State.Status}}'
sudo docker inspect <name> --format '{{json .HostConfig.PortBindings}}'
sudo docker inspect <name> --format '{{range .Mounts}}{{.Source}}->{{.Destination}}{{"\n"}}{{end}}'
sudo docker inspect <name> --format '{{.Config.Cmd}}'
```

## 5. Images

```bash

# pull image
sudo docker pull <image>:<tag>

# retag image
sudo docker tag <source>:<tag> <target>:<new-tag>

# remove image
sudo docker rmi <image>:<tag>
sudo docker rmi -f <image-id>           # force

# remove all images over 100MB
sudo docker images --format "{{.ID}} {{.Size}}" | awk '
/GB/ {print $1}
/MB/ { gsub(/MB/,"",$2); if ($2+0 > 100) print $1 }
' | sort -u | xargs -r sudo docker rmi -f
```

## 8. Troubleshoot stopped container

```bash
# step 1 — check status and config
sudo docker ps -a | grep <name>
sudo docker inspect <name> \
  --format 'Status: {{.State.Status}} | Port: {{json .HostConfig.PortBindings}} | Vol: {{range .Mounts}}{{.Source}}->{{.Destination}}{{end}}'

# step 2a — if config correct, just start
sudo docker start <name>

# step 2b — if config wrong, recreate
IMAGE=$(sudo docker inspect <name> --format '{{.Config.Image}}')
sudo docker rm <name>
sudo docker run -d \
  --name <name> \
  -p <host-port>:<container-port> \
  -v <host-path>:<container-path> \
  $IMAGE

# step 3 — verify
sudo docker ps | grep <name>
curl http://localhost:<host-port>/
```

## 9. Common verify commands

```bash
# container running?
sudo docker ps | grep <name>

# correct image + state?
sudo docker inspect <name> \
  --format 'Image: {{.Config.Image}} | State: {{.State.Status}}'

# correct CMD?
sudo docker inspect <name> --format '{{.Config.Cmd}}'

# correct port mapping?
sudo docker inspect <name> --format '{{json .HostConfig.PortBindings}}'
# expect: {"80/tcp":[{"HostIp":"","HostPort":"8081"}]}

# correct volume mapping?
sudo docker inspect <name> \
  --format '{{range .Mounts}}{{.Source}}->{{.Destination}}{{"\n"}}{{end}}'

# website accessible?
curl http://localhost:<port>/

# file in container?
sudo docker exec <name> ls -l /path/to/file

# file integrity?
md5sum /host/file
sudo docker exec <name> md5sum /container/file
```

## 10. Common errors and fixes

| Error | Cause | Fix |
|---|---|---|
| `cannot remove running container` | `docker rm` without `-f` | `docker rm -f <name>` |
| `container is not running` | container exited | `docker start <name>` |
| `exec: "-it": not found` | `-it` after container name | `docker exec -it <name> /bin/bash` |
| `ps: not found` in exec | minimal image, no ps | use `docker stats` or `docker top` instead |
| `conflict: image in use` | container using the image | `docker rm -f <container>` first |
| `network in use` | containers connected | `docker network disconnect <net> <container>` |
| `port already allocated` | host port taken | `docker ps` to find conflict, `docker rm -f` it |
| `no such container` | wrong name or already deleted | `docker ps -a` to check |

## 11. Quick reference — docker cp syntax

```bash
# ALWAYS: source → destination
docker cp <source> <destination>

# host → container
docker cp /local/file container_name:/remote/path/

# container → host
docker cp container_name:/remote/file /local/path/
```

## 12. Task patterns by type

| Task type | Key command |
|---|---|
| Create container | `docker run -d --name <n> <image>:<tag>` |
| Create with port | `docker run -d --name <n> -p host:container <image>` |
| Create with volume | `docker run -d --name <n> -v host:container <image>` |
| Override CMD | `docker run -d --name <n> <image> <cmd>` |
| Fix stopped container | `docker start <name>` or `docker rm + docker run` |
| Copy host→container | `docker cp /host/file <container>:/path/` |
| Copy container→host | `docker cp <container>:/path/file /host/` |
| Delete container | `docker rm -f <name>` |
| Retag image | `docker tag <src>:<tag> <dst>:<newtag>` |
| Delete image | `docker rmi <image>:<tag>` |
| Create network | `docker network create --driver bridge --subnet x --gateway y <name>` |
| Delete network | `docker network rm <name>` |
