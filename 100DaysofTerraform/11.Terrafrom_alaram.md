## 1. VPC

### Concept
A **VPC (Virtual Private Cloud)** is an isolated network in AWS. It's the foundation everything else sits inside — subnets, EC2 instances, security groups, etc. VPCs have no native name field; naming is via `Name` tag.

### Syntax reference
```hcl
resource "aws_vpc" "<local_name>" {
  cidr_block                       = "<cidr>"     # REQUIRED e.g. "10.0.0.0/16"
  assign_generated_ipv6_cidr_block = true/false   # Amazon-provided IPv6
  enable_dns_support               = true         # default true
  enable_dns_hostnames             = true         # default false

  tags = {
    Name = "<vpc-name>"                           # display name
  }
}
```

### Variants

**IPv4 only (any CIDR):**
```hcl
resource "aws_vpc" "nautilus_vpc" {
  cidr_block = "10.0.0.0/16"
  tags = { Name = "nautilus-vpc" }
}
```

**IPv4 with exact CIDR:**
```hcl
resource "aws_vpc" "nautilus_vpc" {
  cidr_block = "192.168.0.0/24"
  tags = { Name = "nautilus-vpc" }
}
```

**IPv4 + Amazon-provided IPv6:**
```hcl
resource "aws_vpc" "datacenter_vpc" {
  cidr_block                       = "10.0.0.0/16"
  assign_generated_ipv6_cidr_block = true
  tags = { Name = "datacenter-vpc" }
}
```

### Verify
```bash
terraform state show aws_vpc.<name> | grep -E "cidr|ipv6|tags|id"
```

### Watch-outs
- `cidr_block` is always required even when adding IPv6
- `assign_generated_ipv6_cidr_block = true` = Amazon assigns the `/56` automatically
- Name is a tag, not a field

## 2. Security Group

### Concept
A **Security Group** is a stateful virtual firewall controlling inbound/outbound traffic for AWS resources. Rules are defined as `ingress` (inbound) and `egress` (outbound) blocks. Unlike NACLs, SGs are stateful — return traffic is automatically allowed. SG `name` IS a real field (unlike VPC/EIP/EBS which use only tags).

### Syntax reference
```hcl
resource "aws_security_group" "<local_name>" {
  name        = "<sg-name>"           # REQUIRED — real name field
  description = "<text>"              # REQUIRED — immutable after creation
  vpc_id      = "<vpc-id>"            # which VPC

  ingress {                           # inbound rule
    description = "<label>"
    from_port   = <number>            # start of port range
    to_port     = <number>            # end of port range (same as from for single port)
    protocol    = "tcp"/"udp"/"icmp"/"-1"  # -1 = all
    cidr_blocks = ["<cidr>"]
  }

  egress {                            # outbound rule
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    cidr_blocks = ["0.0.0.0/0"]
  }

  tags = { Name = "<sg-name>" }
}

# look up default VPC to attach SG
data "aws_vpc" "default" {
  default = true
}

# look up default SG
data "aws_security_group" "default" {
  vpc_id = data.aws_vpc.default.id
  name   = "default"
}
```

### Example
```hcl
data "aws_vpc" "default" { default = true }

resource "aws_security_group" "devops_sg" {
  name        = "devops-sg"
  description = "Security group for Nautilus App Servers"
  vpc_id      = data.aws_vpc.default.id

  ingress {
    description = "HTTP"
    from_port   = 80
    to_port     = 80
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  ingress {
    description = "SSH"
    from_port   = 22
    to_port     = 22
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  tags = { Name = "devops-sg" }
}
```

### Verify
```bash
terraform state show aws_security_group.<name> | grep -E "name|description|from_port|to_port|cidr"
```

### Watch-outs
- `description` is **immutable** — typo = destroy/recreate
- `name` is a real field here (not just a tag)
- HTTP = TCP/80, SSH = TCP/22, HTTPS = TCP/443

## 3. EC2 Instance

### Concept
An **EC2 instance** is a virtual machine in AWS. Key components: AMI (the OS image), instance type (CPU/RAM), key pair (SSH auth), security groups (firewall). Name is a tag, not a field.

### Syntax reference
```hcl
# generate RSA key
resource "tls_private_key" "<local_name>" {
  algorithm = "RSA"
  rsa_bits  = 4096
}

# register key in AWS
resource "aws_key_pair" "<local_name>" {
  key_name   = "<kp-name>"
  public_key = tls_private_key.<local_name>.public_key_openssh
}

# save private key locally
resource "local_file" "<local_name>" {
  content         = tls_private_key.<local_name>.private_key_pem
  filename        = "/path/to/key.pem"
  file_permission = "0400"
}

resource "aws_instance" "<local_name>" {
  ami                    = "<ami-id>"          # REQUIRED
  instance_type          = "<type>"            # REQUIRED e.g. t2.micro
  key_name               = aws_key_pair.<name>.key_name
  vpc_security_group_ids = ["<sg-id>"]
  subnet_id              = "<subnet-id>"       # optional
  user_data              = "<script>"          # optional

  tags = { Name = "<instance-name>" }
}
```

### Example
```hcl
resource "tls_private_key" "xfusion_kp" {
  algorithm = "RSA"
  rsa_bits  = 4096
}

resource "aws_key_pair" "xfusion_kp" {
  key_name   = "xfusion-kp"
  public_key = tls_private_key.xfusion_kp.public_key_openssh
}

data "aws_vpc" "default" { default = true }
data "aws_security_group" "default" {
  vpc_id = data.aws_vpc.default.id
  name   = "default"
}

resource "aws_instance" "xfusion_ec2" {
  ami                    = "ami-0c101f26f147fa7fd"
  instance_type          = "t2.micro"
  key_name               = aws_key_pair.xfusion_kp.key_name
  vpc_security_group_ids = [data.aws_security_group.default.id]
  tags = { Name = "xfusion-ec2" }
}
```

### Verify
```bash
terraform state show aws_instance.<name> | grep -E "ami|instance_type|key_name|vpc_security_group|tags"
```

## 4. Key Pair

### Concept
A **Key Pair** is an SSH authentication mechanism. AWS stores the public key; you keep the private key. Three resources work together: `tls_private_key` (generates), `aws_key_pair` (registers public key in AWS), `local_file` (saves private key to disk).

### Example
```hcl
resource "tls_private_key" "devops_kp" {
  algorithm = "RSA"
  rsa_bits  = 4096
}

resource "aws_key_pair" "devops_kp" {
  key_name   = "devops-kp"
  public_key = tls_private_key.devops_kp.public_key_openssh
}

resource "local_file" "devops_kp_pem" {
  content         = tls_private_key.devops_kp.private_key_pem
  filename        = "/home/bob/devops-kp.pem"
  file_permission = "0400"
}
```

### Verify
```bash
terraform state show aws_key_pair.<name> | grep key_name
ls -l /home/bob/devops-kp.pem         # expect -r--------
```

## 5. Elastic IP (EIP)

### Concept
An **Elastic IP** is a static public IPv4 address you allocate to your AWS account. Unlike default public IPs (which change on stop/start), EIPs persist until explicitly released. Used for stable public endpoints.

### Syntax reference
```hcl
resource "aws_eip" "<local_name>" {
  domain   = "vpc"                    # REQUIRED — always "vpc" (EC2-Classic retired)
  instance = "<instance-id>"          # optional — attach to instance
  tags = { Name = "<eip-name>" }
}
```

### Example
```hcl
resource "aws_eip" "datacenter_eip" {
  domain = "vpc"
  tags   = { Name = "datacenter-eip" }
}
```

### Verify
```bash
terraform state show aws_eip.<name> | grep -E "public_ip|domain|tags|id"
```

### Watch-outs
- `domain = "vpc"` is mandatory — omitting it causes deprecation errors
- Name is a tag, not a field

## 6. EBS Volume

### Concept
An **EBS Volume** is persistent block storage — a virtual hard disk for EC2 instances. Volumes are AZ-specific. `gp3` is the current recommended general-purpose type (replaces `gp2`).

### Syntax reference
```hcl
resource "aws_ebs_volume" "<local_name>" {
  availability_zone = "<az>"          # REQUIRED e.g. "us-east-1a"
  size              = <GiB>           # REQUIRED integer
  type              = "<type>"        # gp2|gp3|io1|io2|st1|sc1
  iops              = <number>        # gp3/io1/io2 only
  throughput        = <MiB/s>         # gp3 only
  encrypted         = true/false

  tags = { Name = "<vol-name>" }
}
```

### Example
```hcl
resource "aws_ebs_volume" "xfusion_volume" {
  availability_zone = "us-east-1a"
  size              = 2
  type              = "gp3"
  tags              = { Name = "xfusion-volume" }
}
```

### Verify
```bash
terraform state show aws_ebs_volume.<name> | grep -E "availability_zone|size|type|state|tags"
```

### Watch-outs
- `availability_zone` is required — volumes are AZ-locked
- `size` is an integer (GiB), not a string
- `type` defaults to `gp2` if omitted — always specify explicitly

## 7. EBS Snapshot

### Concept
An **EBS Snapshot** is a point-in-time backup of an EBS volume stored in S3 (AWS-managed). Snapshots are incremental — only changed blocks since the last snapshot are stored. Terraform waits for `completed` state automatically.

### Syntax reference
```hcl
# look up existing volume by name tag
data "aws_ebs_volume" "<local_name>" {
  filter {
    name   = "tag:Name"
    values = ["<volume-name>"]
  }
}

resource "aws_ebs_snapshot" "<local_name>" {
  volume_id   = data.aws_ebs_volume.<name>.id   # or aws_ebs_volume.<name>.id
  description = "<text>"                         # immutable after creation

  tags = { Name = "<snapshot-name>" }
}
```

### Example (volume already in state)
```hcl
resource "aws_ebs_snapshot" "devops_vol_ss" {
  volume_id   = aws_ebs_volume.k8s_volume.id
  description = "Devops Snapshot"
  tags        = { Name = "devops-vol-ss" }
}
```

### Verify
```bash
terraform state show aws_ebs_snapshot.<name> | grep -E "id|volume_id|description|state|tags"
# state = "completed" confirms snapshot is ready
```

### Watch-outs
- `description` is **immutable** — copy exactly as required
- Snapshot name is a tag, not a field
- Terraform waits for `completed` automatically — no `time_sleep` needed
- If volume is in state: use `aws_ebs_volume.<name>.id` directly; if not: use `data "aws_ebs_volume"`

## 8. AMI from Instance

### Concept
An **AMI (Amazon Machine Image)** captures an EC2 instance's state — OS, software, config, data volumes. Used for golden images, migration, and backup/recovery. `aws_ami_from_instance` wraps the `CreateImage` API and waits for `available` state.

### Syntax reference
```hcl
# look up existing instance if not in state
data "aws_instance" "<local_name>" {
  filter {
    name   = "tag:Name"
    values = ["<instance-name>"]
  }
}

resource "aws_ami_from_instance" "<local_name>" {
  name               = "<ami-name>"             # REQUIRED — real name field
  source_instance_id = data.aws_instance.<name>.id  # or aws_instance.<name>.id

  tags = { Name = "<ami-name>" }
}
```

### Example (instance already in state)
```hcl
resource "aws_ami_from_instance" "datacenter_ec2_ami" {
  name               = "datacenter-ec2-ami"
  source_instance_id = aws_instance.ec2.id
  tags               = { Name = "datacenter-ec2-ami" }
}
```

### Verify
```bash
terraform state show aws_ami_from_instance.<name> | grep -E "name|state|source_instance|tags"
# state = "available" confirms AMI is ready
```

### Watch-outs
- AMI `name` IS a real field (not just a tag)
- Terraform waits for `available` automatically
- Use data source only when instance is NOT already in Terraform state

## 9. CloudWatch Alarm

### Concept
A **CloudWatch Alarm** watches a single metric over time and fires when it crosses a threshold. Key terms: `period` (seconds per evaluation window), `evaluation_periods` (consecutive windows that must breach), `threshold` (the trigger value), `comparison_operator` (how to compare metric to threshold).

### Syntax reference
```hcl
resource "aws_cloudwatch_metric_alarm" "<local_name>" {
  alarm_name          = "<name>"               # REQUIRED
  comparison_operator = "<operator>"           # REQUIRED
  # GreaterThanThreshold | GreaterThanOrEqualToThreshold
  # LessThanThreshold    | LessThanOrEqualToThreshold

  evaluation_periods  = <number>               # REQUIRED — consecutive windows
  datapoints_to_alarm = <number>               # should equal evaluation_periods
  metric_name         = "<metric>"             # REQUIRED e.g. CPUUtilization
  namespace           = "<namespace>"          # REQUIRED e.g. AWS/EC2
  period              = <seconds>              # REQUIRED — 60|120|300|...
  statistic           = "<stat>"               # Average|Sum|Min|Max|SampleCount
  threshold           = <number>               # REQUIRED

  alarm_description  = "<text>"
  treat_missing_data = "missing"               # missing|breaching|notBreaching|ignore

  dimensions = {
    InstanceId = "<instance-id>"               # ties alarm to specific EC2 instance
  }

  alarm_actions = ["<sns-arn>"]                # optional — notify on ALARM
  ok_actions    = ["<sns-arn>"]                # optional — notify on OK
}
```

### Example
```hcl
resource "aws_cloudwatch_metric_alarm" "nautilus_alarm" {
  alarm_name          = "nautilus-alarm"
  alarm_description   = "Alarm when CPU utilization exceeds 80%"
  comparison_operator = "GreaterThanThreshold"
  evaluation_periods  = 1
  datapoints_to_alarm = 1
  metric_name         = "CPUUtilization"
  namespace           = "AWS/EC2"
  period              = 300
  statistic           = "Average"
  threshold           = 80
  treat_missing_data  = "missing"

  dimensions = {
    InstanceId = "i-12345678"
  }
}
```

### Verify
```bash
terraform state show aws_cloudwatch_metric_alarm.<name> \
  | grep -E "alarm_name|comparison|evaluation|metric|namespace|period|statistic|threshold"

aws --endpoint-url=http://aws:4566 cloudwatch describe-alarms \
  --region us-east-1 --alarm-names "<alarm-name>" \
  --query "MetricAlarms[].{Name:AlarmName,Metric:MetricName,Threshold:Threshold,Period:Period}"
```

### Watch-outs
- `period` is **seconds** — `300` = 5 minutes (not `5`)
- `namespace` is case-sensitive — `AWS/EC2` exactly
- `metric_name` is case-sensitive — `CPUUtilization` exactly
- `comparison_operator` exact string — `GreaterThanThreshold` not `>`
- LocalStack drops CloudWatch tags — `tags = {}` in state is a LocalStack limitation, not a config error
- `terraform plan` showing `No changes` = definitive proof resource is Terraform-managed

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| "Resources not created using Terraform" | state file missing or empty | run `terraform apply`, verify `terraform state list` |
| `tags = {}` in state | LocalStack drops CloudWatch tags | known limitation; remove tags block to stop drift loop |
| `terraform plan` shows tag update loop | LocalStack not persisting tags | remove tags from resource if not graded |
| `Error: no matching VPC found` | default VPC not in LocalStack | omit `vpc_id` — AWS uses default automatically |
| `Error: field is immutable` (SG description) | tried to change description | destroy and recreate with correct description |
| `apply` succeeds but `plan` shows changes | LocalStack state drift | re-apply; if persistent remove the drifting field |
| `init` fails to download provider | registry blocked | check if `.terraform` cache exists; use cached providers |
