# Terraform — SNS Topic (`xfusion-notifications`)

## Concept / purpose

**Amazon SNS (Simple Notification Service)** is a fully managed pub/sub messaging service. It enables decoupled communication between distributed systems, microservices, and event-driven serverless applications.

**Core concepts:**
- **Topic** — a logical access point and communication channel. Publishers send messages to a topic; subscribers receive them.
- **Publisher** → sends message to **Topic** → **Subscribers** (Lambda, SQS, HTTP/S, email, SMS, mobile push)
- **Two topic types:**
  - **Standard** — at-least-once delivery, best-effort ordering, high throughput. Default type.
  - **FIFO** — exactly-once delivery, strict ordering. Name must end in `.fifo`.
- **Use cases:** application alerts, CloudWatch alarm notifications, fan-out to multiple SQS queues, mobile push notifications, email/SMS alerts

**SNS vs SQS:**
- SNS = push-based (fan-out to multiple subscribers simultaneously)
- SQS = pull-based (one consumer processes each message)
- Common pattern: SNS → multiple SQS queues (fan-out)

## Syntax reference

```hcl
resource "aws_sns_topic" "<local_name>" {
  name         = "<topic-name>"           # REQUIRED
                                          # FIFO topics must end in .fifo
  display_name = "<display>"             # optional — shown in email notifications

  # optional — FIFO topic settings
  fifo_topic                  = false    # true for FIFO
  content_based_deduplication = false    # FIFO only

  # optional — encryption
  kms_master_key_id = "<key-id>"

  # optional — delivery policies
  delivery_policy = jsonencode({...})

  tags = { Name = "<topic-name>" }
}

# optional — subscribe an endpoint to the topic
resource "aws_sns_topic_subscription" "<local_name>" {
  topic_arn = aws_sns_topic.<local_name>.arn
  protocol  = "email"                    # email|sqs|lambda|http|https|sms
  endpoint  = "<email-or-arn>"
}

# optional — topic policy
resource "aws_sns_topic_policy" "<local_name>" {
  arn    = aws_sns_topic.<local_name>.arn
  policy = jsonencode({...})
}
```

## Watch-outs

- **SNS topic ARN is the ID** — unlike most resources where `id` is a name or numeric ID, SNS topic `id = arn`. The ARN is how you reference the topic everywhere (subscriptions, policies, CloudWatch actions).
- **FIFO topics need `.fifo` suffix** — standard topics don't. `xfusion-notifications` is a standard topic — no `.fifo` suffix needed.
- **Tags may drift on LocalStack** — same as Kinesis and CloudWatch. If `terraform plan` shows tag changes after apply, remove the `tags` block and re-apply to achieve `No changes`.
- **`name` is a real field** — SNS topic name IS the primary identifier (embedded in the ARN). It cannot be changed after creation — only delete and recreate.
- **One file only** — all in `main.tf`; leave `provider.tf` untouched.
