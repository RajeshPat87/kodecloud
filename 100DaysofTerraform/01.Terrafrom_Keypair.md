## main.tf content

Create `/home/bob/terraform/main.tf` (Explorer → New File → `main.tf`, paste, save):

```hcl
# Generate RSA key pair
resource "tls_private_key" "devops_kp" {
  algorithm = "RSA"
  rsa_bits  = 4096
}

# Register public key as AWS key pair
resource "aws_key_pair" "devops_kp" {
  key_name   = "devops-kp"
  public_key = tls_private_key.devops_kp.public_key_openssh
}

# Save private key to /home/bob/devops-kp.pem
resource "local_file" "devops_kp_pem" {
  content         = tls_private_key.devops_kp.private_key_pem
  filename        = "/home/bob/devops-kp.pem"
  file_permission = "0400"
}
```

## Why each piece

**`tls_private_key`** — generates the RSA key pair in Terraform. `algorithm = "RSA"` satisfies the "type must be rsa" requirement.

**`aws_key_pair`** — registers the public key in AWS under the name `devops-kp` (requirement 1). `public_key_openssh` is the correct format AWS expects.

**`local_file`** — writes the private key PEM to `/home/bob/devops-kp.pem` (requirement 3). `file_permission = "0400"` is the standard SSH private key permission (read-only by owner) — without it the key is too open for SSH to use.

**Three providers used:** `aws` (from `provider.tf`), `tls` and `local` (auto-fetched by `terraform init`).
