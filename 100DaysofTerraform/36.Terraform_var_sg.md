# Terraform — Security Group with Variables (`variables.tf` + `main.tf`)

## Concept / purpose

Same pattern as the VPC variables task — the Security Group name is stored in a variable in `variables.tf` and referenced in `main.tf` via `var.KKE_sg`. This keeps configuration values separate from infrastructure logic.

**File structure:**
```

├── provider.tf       # already exists
├── variables.tf      # NEW — variable KKE_sg = "nautilus-sg"
└── main.tf           # NEW — aws_security_group referencing var.KKE_sg
```

## main.tf content

```hcl
data "aws_vpc" "default" {
  default = true
}

resource "aws_security_group" "nautilus_sg" {
  name        = var.KKE_sg
  description = "Security group for Nautilus"
  vpc_id      = data.aws_vpc.default.id

  tags = {
    Name = var.KKE_sg
  }
}
```

`var.KKE_sg` is used in both `name` (the real SG name field) and `tags.Name` (console display). Unlike VPCs where only the tag is the name, Security Groups have a real `name` field — both must be set.

## Watch-outs

- **SG `name` is a real field** — unlike VPCs (name only via tag), SGs have a real `name` attribute. Set `name = var.KKE_sg` — not just a tag.
- **`description` is required and immutable** — `aws_security_group` requires `description`. It cannot be changed after creation (forces destroy/recreate). Set it once and leave it.
- **`vpc_id` is needed** — without it, Terraform may error or place the SG in an unexpected VPC. The `data "aws_vpc" "default"` lookup finds the default VPC automatically.
- **Same `variables.tf` file can hold multiple variables** — if this task builds on the VPC task, just append `variable "KKE_sg"` to the existing `variables.tf`:
  ```hcl
  # existing
  variable "KKE_vpc" {
    type    = string
    default = "xfusion-vpc"
  }

  # new
  variable "KKE_sg" {
    type    = string
    default = "nautilus-sg"
  }
  ```
- **Two files required** — variable declaration in `variables.tf`, infrastructure in `main.tf`. Don't put them in the same file.
- **`provider.tf` stays untouched.*
