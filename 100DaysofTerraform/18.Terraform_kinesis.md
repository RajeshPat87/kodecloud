# Terraform — Kinesis Data Stream (`nautilus-stream`)

## Concept / purpose

**Amazon Kinesis Data Streams** is a real-time data streaming service. It continuously captures gigabytes of data per second from hundreds of thousands of sources — application logs, IoT telemetry, clickstreams, financial transactions — and makes it available for real-time processing.

**Core concepts:**
- **Stream** — the top-level container. Data flows into and out of a stream.
- **Shard** — the base throughput unit. Each shard provides 1 MB/s write and 2 MB/s read. A stream has one or more shards.
- **Data record** — the unit of data (sequence number + partition key + data blob up to 1 MB).
- **Retention period** — how long records stay in the stream (24 hours default, up to 365 days).
- **Stream modes:**
  - `PROVISIONED` — you specify the number of shards manually. Predictable cost, manual scaling.
  - `ON_DEMAND` — AWS scales shards automatically based on traffic. No capacity planning. Pay per GB ingested/retrieved.

**Use cases:** real-time analytics, log aggregation, event sourcing, IoT data ingestion, feeding downstream services like Lambda, EMR, Kinesis Data Firehose, or Kinesis Data Analytics.

## Syntax reference

```hcl
resource "aws_kinesis_stream" "<local_name>" {
  name             = "<stream-name>"    # REQUIRED
  shard_count      = <number>           # REQUIRED for PROVISIONED mode
                                        # omit for ON_DEMAND mode

  stream_mode_details {
    stream_mode = "PROVISIONED"         # PROVISIONED | ON_DEMAND
  }

  retention_period = <hours>            # optional — 24 to 8760 (default 24)

  shard_level_metrics = [               # optional — enhanced monitoring
    "IncomingBytes",
    "OutgoingRecords",
  ]

  encryption_type = "KMS"              # optional — NONE | KMS
  kms_key_id      = "<key-id>"         # required if encryption_type = KMS

  tags = { Name = "<stream-name>" }
}
```

## main.tf content

```hcl
resource "aws_kinesis_stream" "nautilus_stream" {
  name        = "nautilus-stream"
  shard_count = 1

  stream_mode_details {
    stream_mode = "PROVISIONED"
  }

  tags = {
    Name = "nautilus-stream"
  }
}
```

**Why `shard_count = 1` and `PROVISIONED`:** The task doesn't specify a mode, so `PROVISIONED` with 1 shard is the simplest valid config. `ON_DEMAND` would omit `shard_count` but some LocalStack versions handle `PROVISIONED` more reliably.

## Watch-outs

- **`shard_count` required for `PROVISIONED`** — omitting it with `PROVISIONED` mode errors. Only `ON_DEMAND` mode allows omitting `shard_count`.
- **`terraform plan` must show `No changes`** — this task explicitly requires it. If LocalStack drifts on any attribute after apply, remove that attribute from `main.tf` and re-apply to stop the drift loop (same pattern as CloudWatch tags).
- **Stream takes time to become `ACTIVE`** — Terraform waits automatically. In LocalStack it's instant.
- **`name` is a real field** — not a tag. Kinesis stream names are the primary identifier.
- **One file only** — all in `main.tf`; leave `provider.tf` untouched.
