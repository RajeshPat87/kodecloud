# Terraform — OpenSearch Domain (`nautilus-es`)

## Concept / purpose

**Amazon OpenSearch Service** (formerly Amazon Elasticsearch Service) is a fully managed search and analytics engine built on Apache Lucene. It provides real-time search, log analytics, full-text search, application monitoring, and clickstream analytics.

**Core concepts:**
- **Domain** — the top-level OpenSearch resource. Analogous to a "cluster." Contains nodes, storage, and the OpenSearch engine.
- **Engine version** — `OpenSearch_2.11`, `OpenSearch_1.3`, or legacy `Elasticsearch_7.10` etc.
- **Instance type** — the node type (CPU/RAM). `t3.small.search` is the smallest/cheapest for dev/test.
- **EBS storage** — OpenSearch uses EBS volumes for data storage. Must be configured explicitly.
- **Cluster config** — number of data nodes, dedicated master nodes, availability zones.

**OpenSearch vs Elasticsearch:**
- AWS renamed the service in 2021 when they forked from Elasticsearch 7.10
- Terraform resource is `aws_opensearch_domain` (old: `aws_elasticsearch_domain`)
- Engine versions: `OpenSearch_x.x` or `Elasticsearch_x.x`

**Use cases:** log analytics (ELK-style), full-text search, application monitoring, security analytics, business intelligence dashboards via OpenSearch Dashboards (formerly Kibana).

**Note on creation time** — OpenSearch domains take **10–15 minutes** to become `Active` in real AWS. Terraform waits automatically. In LocalStack it's faster but may still take a moment.

## Syntax reference

```hcl
resource "aws_opensearch_domain" "<local_name>" {
  domain_name    = "<name>"             # REQUIRED — lowercase, hyphens OK
  engine_version = "OpenSearch_2.11"   # OpenSearch_x.x or Elasticsearch_x.x

  cluster_config {
    instance_type            = "t3.small.search"  # node size
    instance_count           = 1                   # number of data nodes
    dedicated_master_enabled = false               # master nodes separate?
    zone_awareness_enabled   = false               # multi-AZ?
  }

  ebs_options {
    ebs_enabled = true
    volume_type = "gp2"                # gp2 | gp3 | io1
    volume_size = 10                   # GiB
  }

  access_policies = jsonencode({       # optional — resource-based access policy
    Version = "2012-10-17"
    Statement = [{
      Effect    = "Allow"
      Principal = { AWS = "*" }
      Action    = "es:*"
      Resource  = "arn:aws:es:us-east-1:*:domain/<name>/*"
    }]
  })

  encrypt_at_rest {
    enabled = true
  }

  node_to_node_encryption {
    enabled = true
  }

  domain_endpoint_options {
    enforce_https = true
  }

  tags = { Name = "<domain-name>" }
}
```

```hcl
  domain_name    = "nautilus-es"
```

```hcl
  # remove tags block
```

**`engine_version` drifting:**
```bash

# if it shows a different version LocalStack returns, match it
# e.g. change to "Elasticsearch_7.10" or "OpenSearch_1.3"
```

## Watch-outs

- **Creation takes time** — `terraform apply` blocks until the domain is `Active`. In real AWS this is 10–15 minutes. Don't interrupt it.
- **`es` endpoint in provider.tf** — OpenSearch uses the `es` endpoint in LocalStack (`es = "http://aws:4566"`), not `opensearch`. Verify with `grep es provider.tf`.
- **`aws_opensearch_domain` not `aws_elasticsearch_domain`** — the old resource name was `aws_elasticsearch_domain`. Use the new `aws_opensearch_domain` with provider version 5.x.
- **`engine_version` format** — `OpenSearch_2.11` (capital O, underscore, version). `Elasticsearch_7.10` for legacy. Wrong format = API error.
- **`ebs_options` required** — OpenSearch requires EBS storage config. Omitting it causes a "EBS options must be specified" error.
- **`instance_type` must end in `.search`** — `t3.small.search` not `t3.small`. All OpenSearch instance types have `.search` suffix.
- **Tags may drift** — same LocalStack pattern as Kinesis and CloudWatch. Remove tags block if needed.
- **One file only** — all in `main.tf`; leave `provider.tf` untouched.
