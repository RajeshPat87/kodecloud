## Watch-outs

- **EIP has no native `name` field** — naming is via `tags = { Name = var.KKE_eip }`. Same as VPCs.
- **`domain = "vpc"` is mandatory** — EC2-Classic is retired; always set `domain = "vpc"` for modern AWS.
- **Tags may drift on LocalStack** — if `terraform plan` shows tag drift after apply, remove the `tags` block (same LocalStack limitation as Kinesis/CloudWatch). The variable is still used; just the tag persistence is the issue.
- **If `variables.tf` already exists** from a previous task (VPC or SG), append the new variable — don't overwrite the file:
  ```hcl
  # append to existing variables.tf
  variable "KKE_eip" {
    type        = string
    default     = "xfusion-eip"
    description = "Name of the Elastic IP to be created"
  }
  ```
- **Two files required** — `variables.tf` for the variable, `main.tf` for the resource.
- **`provider.tf` stays untouched.**
