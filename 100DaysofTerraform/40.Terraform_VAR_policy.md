## main.tf content

```hcl
resource "aws_iam_policy" "iampolicy_mariyam" {
  name        = var.KKE_iampolicy
  description = "IAM policy for ${var.KKE_iampolicy}"

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect   = "Allow"
        Action   = "ec2:Describe*"
        Resource = "*"
      }
    ]
  })

  tags = {
    Name = var.KKE_iampolicy
  }
}
```

`var.KKE_iampolicy` used in:
- `name` — the real IAM policy name (primary identifier, has its own ARN)
- `description` — interpolated: `"IAM policy for iampolicy_mariyam"`
- `tags.Name` — console display name

## IAM policy syntax reference (complete)

```hcl
resource "aws_iam_policy" "<local_name>" {
  name        = "<policy-name>"         # REQUIRED — unique policy name
  description = "<text>"               # optional — immutable after creation
  path        = "/"                    # optional — hierarchy path

  # REQUIRED — the policy document
  policy = jsonencode({
    Version = "2012-10-17"             # fixed string — always this date
    Statement = [
      {
        Sid      = "<optional-id>"     # optional statement ID
        Effect   = "Allow"             # Allow | Deny
        Action   = [                   # API actions — string or list
          "ec2:Describe*",
          "s3:GetObject",
          "s3:ListBucket"
        ]
        Resource = "*"                 # ARN or * (Describe actions require *)
        Condition = {                  # optional — conditional logic
          StringEquals = {
            "aws:RequestedRegion" = "us-east-1"
          }
        }
      }
    ]
  })

  tags = { Name = "<policy-name>" }
}

# common action patterns
# EC2 read-only:    "ec2:Describe*"
# S3 read-only:     ["s3:GetObject", "s3:ListBucket", "s3:ListAllMyBuckets"]
# S3 full access:   "s3:*"
# IAM read-only:    ["iam:Get*", "iam:List*"]
# All services:     "*"
# CloudWatch logs:  ["logs:CreateLogGroup", "logs:CreateLogStream", "logs:PutLogEvents"]
```

## Watch-outs

- **`policy` document is required** — `aws_iam_policy` must have a valid JSON policy document. Unlike roles (which need a trust policy) and users/groups (which need nothing), policies are literally just a name + JSON document. The JSON is the entire point of the resource.
- **`Version = "2012-10-17"` is a fixed string** — not today's date. It's the IAM policy language version and never changes.
- **`description` is immutable** — once set, it cannot be changed without destroying and recreating the policy. Set it carefully.
- **Policy `id` is the ARN** — unlike most resources where `id` is a name or short string, `aws_iam_policy`'s `id` is the full ARN (`arn:aws:iam::account:policy/name`). Use `.arn` when referencing in attachments.
- **`name` is a real field** — IAM policies have a real `name` field (not just a tag). It's embedded in the ARN.
- **If `variables.tf` already exists** from a previous task, append:
  ```hcl
  variable "KKE_iampolicy" {
    type        = string
    default     = "iampolicy_mariyam"
    description = "Name of the IAM policy to be created"
  }
  ```
- **Two files required** — `variables.tf` for the variable, `main.tf` for the resource.
- **`provider.tf` stays untouched.**
