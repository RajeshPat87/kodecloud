# Terraform — Private S3 Bucket (`xfusion-s3-15703`)

## Concept / purpose

**Amazon S3 (Simple Storage Service)** is AWS's object storage service — store and retrieve any amount of data at any time. S3 buckets are the top-level containers; objects (files) live inside them.

**Public access blocking** — S3 has four independent block settings that work as a layered defense:
- `block_public_acls` — blocks new ACLs that grant public access
- `ignore_public_acls` — ignores existing public ACLs on the bucket and objects
- `block_public_policy` — blocks bucket policies that grant public access
- `restrict_public_buckets` — restricts access to buckets with public policies to only AWS services and authorized users

Setting all four to `true` = fully private bucket — no public access via ACL or policy, regardless of what individual objects or policies say. This is the AWS-recommended default for all new buckets since 2023.

**Two separate resources** are needed:
- `aws_s3_bucket` — creates the bucket
- `aws_s3_bucket_public_access_block` — applies the four block settings (separate resource because AWS manages them independently via a different API call)

## Syntax reference

```hcl
# create the bucket
resource "aws_s3_bucket" "<local_name>" {
  bucket        = "<bucket-name>"      # REQUIRED — globally unique name
  force_destroy = true/false           # delete bucket even if non-empty on destroy

  tags = { Name = "<bucket-name>" }
}

# block all public access
resource "aws_s3_bucket_public_access_block" "<local_name>" {
  bucket = aws_s3_bucket.<local_name>.id   # REQUIRED — reference the bucket

  block_public_acls       = true/false
  ignore_public_acls      = true/false
  block_public_policy     = true/false
  restrict_public_buckets = true/false
}

# optional — set versioning
resource "aws_s3_bucket_versioning" "<local_name>" {
  bucket = aws_s3_bucket.<local_name>.id
  versioning_configuration {
    status = "Enabled"    # Enabled | Suspended | Disabled
  }
}

# optional — set ownership controls
resource "aws_s3_bucket_ownership_controls" "<local_name>" {
  bucket = aws_s3_bucket.<local_name>.id
  rule {
    object_ownership = "BucketOwnerPreferred"   # BucketOwnerPreferred | ObjectWriter | BucketOwnerEnforced
  }
}
```

## Watch-outs

- **Two resources required** — `aws_s3_bucket` alone does NOT block public access; you must also create `aws_s3_bucket_public_access_block` separately. This is a common mistake that fails grading.
- **Bucket name is globally unique** — `xfusion-s3-15703` is already unique by virtue of the number suffix; don't change it.
- **`bucket` in `public_access_block` must reference the bucket ID** — `aws_s3_bucket.xfusion_s3.id` (the bucket name is also the ID for S3).
- **All four settings must be `true`** — "block all public access" means all four, not just one or two.
- **LocalStack S3 endpoint** — confirm `s3 = "http://aws:4566"` in `provider.tf`; LocalStack routes S3 separately from other services.
- **One file only** — all in `main.tf`; leave `provider.tf` untouched.
