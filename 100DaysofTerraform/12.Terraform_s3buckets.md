# Terraform Public S3 Bucket Configuration

## main.tf

```hcl
provider "aws" {
  region = "us-east-1"
}

# Public S3 Bucket
resource "aws_s3_bucket" "nautilus-s3-32260" {
  bucket = "nautilus-s3-32260"

  tags = {
    Name        = "nautilus-s3-32260"
    Environment = "Production"
    Access      = "Public"
  }
}

# S3 Bucket ACL - Public Read
resource "aws_s3_bucket_acl" "nautilus-s3-32260-acl" {
  bucket = aws_s3_bucket.nautilus-s3-32260.id
  acl    = "public-read"
}

# S3 Bucket Ownership Controls (required for new buckets)
resource "aws_s3_bucket_ownership_controls" "nautilus-s3-32260-ownership" {
  bucket = aws_s3_bucket.nautilus-s3-32260.id

  rule {
    object_ownership = "BucketOwnerPreferred"
  }
}

# S3 Bucket Public Access Block (disable restrictions)
resource "aws_s3_bucket_public_access_block" "nautilus-s3-32260-public" {
  bucket = aws_s3_bucket.nautilus-s3-32260.id

  block_public_acls       = false
  block_public_policy     = false
  ignore_public_acls      = false
  restrict_public_buckets = false
}
```

## Configuration Breakdown

### 1. **AWS Provider**
```hcl
provider "aws" {
  region = "us-east-1"
}
```
- Configures AWS provider in the `us-east-1` region as required

***

### 2. **S3 Bucket Resource**
```hcl
resource "aws_s3_bucket" "nautilus-s3-32260" {
  bucket = "nautilus-s3-32260"
  
  tags = {
    Name        = "nautilus-s3-32260"
    Environment = "Production"
    Access      = "Public"
  }
}
```
- Creates S3 bucket named `nautilus-s3-32260`
- Adds tags for identification and cost tracking

***

### 3. **S3 Bucket ACL (Access Control List)**
```hcl
resource "aws_s3_bucket_acl" "nautilus-s3-32260-acl" {
  bucket = aws_s3_bucket.nautilus-s3-32260.id
  acl    = "public-read"
}
```
- **`acl = "public-read"`** - Makes the bucket publicly accessible
- Anyone on the internet can read objects in the bucket
- Only the bucket owner can write/delete objects

***

### 4. **S3 Bucket Ownership Controls**
```hcl
resource "aws_s3_bucket_ownership_controls" "nautilus-s3-32260-ownership" {
  bucket = aws_s3_bucket.nautilus-s3-32260.id

  rule {
    object_ownership = "BucketOwnerPreferred"
  }
}
```
- Required for new S3 buckets (AWS requirement since April 2023)
- `BucketOwnerPreferred` - Objects uploaded to the bucket will be owned by the bucket owner

***

### 5. **S3 Bucket Public Access Block**
```hcl
resource "aws_s3_bucket_public_access_block" "nautilus-s3-32260-public" {
  bucket = aws_s3_bucket.nautilus-s3-32260.id

  block_public_acls       = false
  block_public_policy     = false
  ignore_public_acls      = false
  restrict_public_buckets = false
}
```
- **Disables all public access restrictions** to allow public ACL
- All four settings set to `false` to enable public access:
  - `block_public_acls = false` - Allows public ACLs
  - `block_public_policy = false` - Allows public bucket policies
  - `ignore_public_acls = false` - Respects public ACLs
  - `restrict_public_buckets = false` - Allows public bucket access

## Security Considerations

### ⚠️ Public Bucket Risks

Since this bucket is **publicly accessible**:

- **Anyone can read** objects in the bucket
- **Sensitive data should NOT** be stored here
- **Costs** can accumulate if others access large files
- **Compliance** requirements may be violated

### Best Practices

1. **Use for static website hosting** or public assets only
2. **Enable versioning** to protect against accidental deletion
3. **Enable server access logging** to track who accesses your data
4. **Consider CloudFront** for better performance and cost control
5. **Set up lifecycle policies** to manage storage costs
6. **Monitor with CloudWatch** for unusual access patterns

## Alternative: Private Bucket with Public Objects

If you need only specific objects to be public (recommended):

```hcl
# Private bucket
resource "aws_s3_bucket" "nautilus-s3-32260" {
  bucket = "nautilus-s3-32260"
}

# Keep public access block enabled
resource "aws_s3_bucket_public_access_block" "nautilus-s3-32260-public" {
  bucket = aws_s3_bucket.nautilus-s3-32260.id

  block_public_acls   = true
  block_public_policy = true
  ignore_public_acls  = true
  restrict_public_buckets = true
}

# Make specific objects public using bucket policy
resource "aws_s3_bucket_policy" "nautilus-s3-32260-policy" {
  bucket = aws_s3_bucket.nautilus-s3-32260.id

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Sid       = "PublicReadGetObject"
        Effect    = "Allow"
        Principal = "*"
        Action    = "s3:GetObject"
        Resource  = "${aws_s3_bucket.nautilus-s3-32260.arn}/public/*"
      }
    ]
  })
}
```
