# Terraform — IAM User (`iamuser_kareem`)

## Concept / purpose

**IAM (Identity and Access Management)** is AWS's authentication and authorization service. It controls *who* can access AWS resources and *what* they can do.

**IAM User** — a permanent identity representing a person or application. Unlike roles (temporary credentials), users have long-term credentials: console passwords and/or access keys. IAM is a **global service** — users are not region-specific, but the provider still routes API calls through the configured region.

An IAM user alone does nothing — it's the foundation. You then attach policies, add it to groups, or generate access keys to give it capabilities. This task is just the user creation step.

## Syntax reference

```hcl
resource "aws_iam_user" "<local_name>" {
  name          = "<username>"          # REQUIRED — IAM username
  path          = "/"                   # optional — hierarchy path, default "/"
  force_destroy = true/false            # delete user even if it has non-Terraform resources

  tags = { Name = "<username>" }
}

# optional — console login profile (password)
resource "aws_iam_user_login_profile" "<local_name>" {
  user                    = aws_iam_user.<local_name>.name
  password_reset_required = true
}

# optional — access keys (programmatic access)
resource "aws_iam_access_key" "<local_name>" {
  user = aws_iam_user.<local_name>.name
}

# optional — add to group
resource "aws_iam_user_group_membership" "<local_name>" {
  user   = aws_iam_user.<local_name>.name
  groups = ["<group-name>"]
}

# optional — attach policy directly
resource "aws_iam_user_policy_attachment" "<local_name>" {
  user       = aws_iam_user.<local_name>.name
  policy_arn = "<policy-arn>"
}
```

## Watch-outs

- **IAM is global** — users are not region-specific. The provider routes API calls through `us-east-1` as configured in `provider.tf`, but the user itself has no region.
- **`name` is the real username** — it's the IAM username used for login and API calls. Must match exactly: `iamuser_kareem` (underscore, not hyphen).
- **User alone has no permissions** — this task only creates the user. Policies, groups, and access keys are separate resources added later if needed.
- **`force_destroy = true`** — optional but useful in labs; allows `terraform destroy` to delete the user even if it has access keys or other attached resources not managed by Terraform.
- **One file only** — all in `main.tf`; leave `provider.tf` untouched.
