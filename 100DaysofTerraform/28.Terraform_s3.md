## Why `aws_s3_bucket_versioning` not inline versioning

Older Terraform AWS provider versions used a `versioning {}` block inside `aws_s3_bucket`. Provider 4.x+ deprecated that in favour of the standalone `aws_s3_bucket_versioning` resource — same pattern as `aws_s3_bucket_public_access_block`. The standalone resource is the correct modern approach and is what the provider expects.
