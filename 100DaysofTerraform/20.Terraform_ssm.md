# Terraform — SSM Parameter (`devops-ssm-parameter`)

## Concept / purpose

**AWS Systems Manager Parameter Store** is a secure, hierarchical storage service for configuration data and secrets. It lets you store, retrieve, and manage configuration values centrally — avoiding hardcoded values in code or config files.

**Parameter types:**
- `String` — plain text value. No encryption. Use for non-sensitive config (URLs, names, flags).
- `StringList` — comma-separated list of plain text values.
- `SecureString` — encrypted using KMS. Use for passwords, API keys, connection strings.

**Parameter tiers:**
- `Standard` — free, up to 10,000 parameters, max 4KB value size. Default.
- `Advanced` — paid, up to 100,000 parameters, max 8KB, supports parameter policies (TTL/expiry).

**Common use cases:**
- Store database connection strings, feature flags, environment-specific config
- Reference in EC2 user data, ECS task definitions, Lambda environment variables
- Replace `.env` files with centrally managed, auditable config
- Feed values into Terraform via `data "aws_ssm_parameter"`

**Naming convention** — parameters support hierarchical paths:
```
/myapp/prod/db_host
/myapp/prod/db_password
/myapp/dev/db_host
```
Flat names (`devops-ssm-parameter`) are also valid.

## Syntax reference

```hcl
resource "aws_ssm_parameter" "<local_name>" {
  name        = "<param-name>"          # REQUIRED — name or /path/name
  type        = "<type>"                # REQUIRED — String|StringList|SecureString
  value       = "<value>"              # REQUIRED — the parameter value

  description = "<text>"               # optional
  tier        = "Standard"             # Standard | Advanced | Intelligent-Tiering
  data_type   = "text"                 # text | aws:ec2:image (for AMI IDs)

  # SecureString only
  key_id      = "<kms-key-id>"         # optional — defaults to AWS managed key

  # optional — overwrite existing parameter (useful for updates)
  overwrite   = true

  tags = { Name = "<param-name>" }
}

# read an existing parameter (data source)
data "aws_ssm_parameter" "<local_name>" {
  name            = "<param-name>"
  with_decryption = true               # true for SecureString
}
# access value: data.aws_ssm_parameter.<local_name>.value
```

## Watch-outs

- **`type` is case-sensitive** — `"String"` (capital S), not `"string"`. Valid values: `String`, `StringList`, `SecureString`.
- **`value` is stored in state in plaintext** — even for `SecureString`, the value appears in `terraform.tfstate`. Never commit state files to Git when using `SecureString`.
- **`overwrite = true`** — add this if you need to update an existing parameter's value. Without it, Terraform errors if the parameter already exists with a different value.
- **Hierarchical names use `/` prefix** — `/myapp/prod/db_host` is valid. The task uses a flat name `devops-ssm-parameter` (no slash) which is also valid.
- **`name` is the ID** — like SNS, the parameter name is its primary identifier and the `id` in state.
- **One file only** — all in `main.fd`; leave `provider.tf` untouched.
