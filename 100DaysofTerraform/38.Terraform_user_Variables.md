## main.tf content

```hcl
resource "aws_iam_user" "iamuser_anita" {
  name = var.KKE_user

  tags = {
    Name = var.KKE_user
  }
}
```

`var.KKE_user` used in both `name` (the real IAM username field) and `tags.Name` (console display). The `name` field is the primary identifier — it's what's used for login, API calls, and policy attachments.

## Watch-outs

- **IAM `name` is the real username** — used for login, API calls, policy attachments. Must be exact: `iamuser_anita` (underscore, all lowercase).
- **IAM is global** — not region-specific. Provider routes the API call through `us-east-1` as configured but the user is available globally.
- **`force_destroy = true`** — optional but lab-friendly. Allows `terraform destroy` to delete the user even if it has access keys or attached policies not managed by Terraform.
- **If `variables.tf` already exists** from a previous task, append — don't overwrite:
  ```hcl
  # append to existing variables.tf
  variable "KKE_user" {
    type        = string
    default     = "iamuser_anita"
    description = "Name of the IAM user to be created"
  }
  ```
- **Two files required** — `variables.tf` for the variable, `main.tf` for the resource.
- **`provider.tf` stays untouched.**
