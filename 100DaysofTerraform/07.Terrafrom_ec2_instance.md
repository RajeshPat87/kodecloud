# Terraform — EC2 Instance (`xfusion-ec2`) with RSA Key + Default SG

## Concept / purpose

This task provisions a complete EC2 instance with three supporting pieces:

**EC2 instance** — a virtual machine in AWS. The `Name` tag is what the AWS console displays as the instance name; there's no native name field on EC2 instances.

**RSA key pair** — SSH authentication for the instance. Terraform's `tls_private_key` generates the RSA pair locally; `aws_key_pair` uploads the public half to AWS. The instance references the key pair name so AWS injects the public key into `~/.ssh/authorized_keys` at launch, enabling SSH access without passwords.

**Default security group** — every VPC has a pre-existing "default" security group. Attaching it (via a data source lookup) means the instance inherits whatever inbound/outbound rules the default SG already has, without creating a new one. This satisfies "attach the default security group" without modifying it.

The three providers used: `aws` (EC2 + key pair), `tls` (RSA key generation), all auto-fetched by `terraform init` alongside the existing `aws` provider.

## main.tf content

Paste into `/home/bob/terraform/main.tf`:

```hcl
# Generate RSA key pair
resource "tls_private_key" "xfusion_kp" {
  algorithm = "RSA"
  rsa_bits  = 4096
}

# Register public key as AWS key pair named xfusion-kp
resource "aws_key_pair" "xfusion_kp" {
  key_name   = "xfusion-kp"
  public_key = tls_private_key.xfusion_kp.public_key_openssh
}

# Look up the default VPC
data "aws_vpc" "default" {
  default = true
}

# Look up the default security group in the default VPC
data "aws_security_group" "default" {
  vpc_id = data.aws_vpc.default.id
  name   = "default"
}

# EC2 instance
resource "aws_instance" "xfusion_ec2" {
  ami                    = "ami-0c101f26f147fa7fd"
  instance_type          = "t2.micro"
  key_name               = aws_key_pair.xfusion_kp.key_name
  vpc_security_group_ids = [data.aws_security_group.default.id]

  tags = {
    Name = "xfusion-ec2"
  }
}
```

## Watch-outs

- **`tls` provider auto-fetched** — `terraform init` pulls it automatically; no manual install needed. If the registry is blocked in the lab, the `.terraform` cache usually has it pre-populated.
- **Default SG lookup needs default VPC** — the data source chain is `default VPC → default SG`. If LocalStack hasn't pre-created the default VPC/SG, the data source errors. Fallback: remove `vpc_security_group_ids` entirely — AWS/LocalStack attaches the default SG automatically when none is specified.
- **Key is "create," not "use existing"** — `tls_private_key` + `aws_key_pair` together satisfy "create a new RSA key." Just referencing a pre-existing key name would miss the requirement.
- **`Name` tag, not a name field** — EC2 instances have no native name attribute; `tags = { Name = ... }` is the AWS convention for naming instances.
- **One file only** — all in `main.tf`; leave `provider.tf` untouched.
