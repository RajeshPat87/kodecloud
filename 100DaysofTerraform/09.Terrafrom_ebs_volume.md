# Terraform — Create EBS Volume (`xfusion-volume`)

## Concept / purpose

An **EBS (Elastic Block Store) volume** is a persistent block storage device in AWS — think of it as a virtual hard disk that you attach to EC2 instances. Unlike instance store (ephemeral), EBS volumes persist independently of the instance lifecycle: you can detach from one instance and reattach to another, or keep the data after an instance is terminated.

**Volume types:**
- `gp2` — previous-gen general purpose SSD (baseline 3 IOPS/GB)
- `gp3` — current-gen general purpose SSD (3000 IOPS baseline, independently configurable throughput) — **preferred for new volumes**
- `io1/io2` — provisioned IOPS for high-performance databases
- `st1/sc1` — throughput-optimized HDD for sequential workloads

**`gp3` is the correct modern choice** — lower cost than `gp2` with better and more flexible performance. AWS recommends `gp3` for all new general-purpose workloads.

EBS volumes are **AZ-specific** — a volume in `us-east-1a` can only attach to instances in `us-east-1a`. The `availability_zone` field is required; without it Terraform errors.

## Syntax reference — `aws_ebs_volume`

```hcl
resource "aws_ebs_volume" "<local_name>" {
  availability_zone = "<az>"          # REQUIRED — e.g. "us-east-1a"
  size              = <number>         # GiB — e.g. 2
  type              = "<type>"         # gp2, gp3, io1, io2, st1, sc1
  iops              = <number>         # only for gp3/io1/io2 (optional for gp3)
  throughput        = <number>         # MiB/s — gp3 only (optional)
  encrypted         = true/false       # encrypt at rest
  kms_key_id        = "<arn>"          # custom KMS key (optional)
  snapshot_id       = "<snap-id>"      # restore from snapshot (optional)

  tags = {
    Name = "<display-name>"            # how volume appears in console
  }
}
```

**Minimum required fields:**
```hcl
resource "aws_ebs_volume" "example" {
  availability_zone = "us-east-1a"
  size              = 2
  type              = "gp3"

  tags = {
    Name = "example-volume"
  }
}
```

## Watch-outs

- **`availability_zone` is required** — `aws_ebs_volume` errors without it. Use any AZ in the region: `us-east-1a`, `us-east-1b`, `us-east-1c` all satisfy "region us-east-1."
- **`size` is an integer (GiB), not a string** — `size = 2` not `size = "2"`. Terraform accepts the number directly.
- **`type` defaults to `gp2` if omitted** — always specify `gp3` explicitly for new volumes.
- **EBS has no native name field** — naming is always `tags = { Name = ... }`. Same pattern as VPC, EC2 instance, EIP.
- **`state = "available"` means unattached** — once attached to an instance it becomes `in-use`. For this task, `available` is the expected post-apply state.
- **One file only** — all in `main.tf`; leave `provider.tf` untouched.
