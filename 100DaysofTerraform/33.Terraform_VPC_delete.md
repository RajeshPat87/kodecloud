## VPC — quick syntax reference (for the code that stays in main.tf)

```hcl
resource "aws_vpc" "devops_vpc" {
  cidr_block           = "10.0.0.0/16"
  enable_dns_support   = true
  enable_dns_hostnames = true

  tags = {
    Name = "devops-vpc"
  }
}
```

**VPC dependency watch-out** — if the VPC had associated resources (subnets, internet gateways, security groups, route tables) those must be deleted first, or they'll block VPC deletion with a `DependencyViolation` error. Terraform handles this automatically if those resources are also in state and targeted together:

```bash
# if VPC deletion errors on dependencies, check what's attached
aws --endpoint-url=http://aws:4566 ec2 describe-subnets \
  --filters "Name=vpc-id,Values=<vpc-id>" \
  --query "Subnets[].SubnetId"

aws --endpoint-url=http://aws:4566 ec2 describe-internet-gateways \
  --filters "Name=attachment.vpc-id,Values=<vpc-id>" \
  --query "InternetGateways[].InternetGatewayId"

# delete dependencies first then retry vpc destroy
terraform destroy -target=aws_subnet.<name> -auto-approve
terraform destroy -target=aws_internet_gateway.<name> -auto-approve
terraform destroy -target=aws_vpc.devops_vpc -auto-approve
```

In this task the VPC is standalone (no associated resources mentioned), so the targeted destroy should complete cleanly in one command.
