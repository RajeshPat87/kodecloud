Simple pod manifest — no deployment, just a bare Pod. Two things graded literally: the label `app: nginx_app` and the container name `nginx-container`. On the jump host.

## Create and apply

```bash
cat <<'EOF' | kubectl apply -f -
apiVersion: v1
kind: Pod
metadata:
  name: pod-nginx
  labels:
    app: nginx_app
spec:
  containers:
    - name: nginx-container
      image: nginx:latest
EOF
```

## Verify

```bash
kubectl get pod pod-nginx
kubectl describe pod pod-nginx | grep -E "Name:|Image:|Labels:|State:"
```

Expected:
```
NAME        READY   STATUS    RESTARTS   AGE
pod-nginx   1/1     Running   0          ...
```

`describe` should show:
```
Name:         pod-nginx
Labels:       app=nginx_app
Image:        nginx:latest
```

## Requirement trace

| Requirement | Evidence |
|---|---|
| Pod name `pod-nginx` | `metadata.name: pod-nginx` |
| Image `nginx:latest` | `image: nginx:latest` |
| Label `app: nginx_app` | `labels: app: nginx_app` |
| Container name `nginx-container` | `name: nginx-container` |

That's the whole task — single `kubectl apply` and the pod is running. No deployment, no service needed.
