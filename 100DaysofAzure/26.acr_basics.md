# Runbook and Documentation: Azure Container Registry Build and Push

## Overview
This document provides the runbook and dynamic OTS script for creating an Azure Container Registry (ACR), building a Docker image from `/root/pyapp` on the `azure-client` host, and pushing the image to ACR with the `latest` tag. The registry required by the task is `devopsacr1923`, it must be created in `East US`, and the SKU must be `Basic`. [learn.microsoft](https://learn.microsoft.com/en-us/azure/container-registry/container-registry-get-started-azure-cli)

## Requirement Summary
The requested work includes the following mandatory items: [youtube](https://www.youtube.com/watch?v=3i8LrJwhboQ)

- Create an Azure Container Registry named `devopsacr1923`. [youtube](https://www.youtube.com/watch?v=3i8LrJwhboQ)
- Create it in `East US`. [learn.microsoft](https://learn.microsoft.com/en-us/azure/container-registry/container-registry-get-started-azure-cli)
- Use the `Basic` pricing tier. [learn.microsoft](https://learn.microsoft.com/en-us/azure/container-registry/container-registry-get-started-azure-cli)
- Use the Dockerfile already present in `/root/pyapp` on `azure-client`. [youtube](https://www.youtube.com/watch?v=3i8LrJwhboQ)
- Build the Docker image and push it to ACR with tag `latest`. [dev](https://dev.to/s3cloudhub/unlock-the-power-of-azure-cli-push-docker-images-to-acr-with-ease-44e4)

## Notes on Naming and Repository Tagging
In Azure, the ACR instance name must be globally unique, lowercase, and alphanumeric. The image pushed to ACR should be tagged using the registry login server format `<acr-name>.azurecr.io/<repository>:<tag>`, so the pushed image path will be `devopsacr1923.azurecr.io/devopsacr1923:latest`. [jonnychipz](https://jonnychipz.com/2021/02/22/create-and-push-a-docker-image-to-azure-container-registry/)

## Dynamic OTS Script
The following script dynamically discovers the current Azure CLI resource group context, creates the ACR if needed, logs in to the registry, builds the Docker image from `/root/pyapp`, tags it correctly for ACR, pushes it, and verifies the repository and tag. [learn.microsoft](https://learn.microsoft.com/en-us/cli/azure/acr?view=azure-cli-latest)

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "=== STEP 0: Azure login ==="
# showcreds   # uncomment if required by the lab
az account show >/dev/null 2>&1 || az login --use-device-code

echo
echo "=== STEP 1: Dynamic context discovery ==="
RG="$(az group list --query '[0].name' -o tsv)"
LOCATION="eastus"
ACR_NAME="devopsacr1923"
ACR_SKU="Basic"
APP_DIR="/root/pyapp"
LOCAL_IMAGE="${ACR_NAME}:latest"

if [[ -z "${RG}" ]]; then
  echo "ERROR: No resource group found in current subscription context."
  exit 1
fi

if [[ ! -d "${APP_DIR}" ]]; then
  echo "ERROR: Application directory ${APP_DIR} not found."
  exit 1
fi

if [[ ! -f "${APP_DIR}/Dockerfile" ]]; then
  echo "ERROR: Dockerfile not found under ${APP_DIR}."
  exit 1
fi

echo "Resource Group : ${RG}"
echo "Location       : ${LOCATION}"
echo "ACR Name       : ${ACR_NAME}"
echo "ACR SKU        : ${ACR_SKU}"
echo "App Directory  : ${APP_DIR}"

echo
echo "=== STEP 2: Create ACR if it does not exist ==="
if az acr show --name "${ACR_NAME}" >/dev/null 2>&1; then
  echo "ACR ${ACR_NAME} already exists. Skipping create."
else
  az acr create \
    --resource-group "${RG}" \
    --name "${ACR_NAME}" \
    --sku "${ACR_SKU}" \
    --location "${LOCATION}" \
    -o table
fi

echo
echo "=== STEP 3: Login to ACR ==="
az acr login --name "${ACR_NAME}"

echo
echo "=== STEP 4: Get ACR login server dynamically ==="
ACR_LOGIN_SERVER="$(az acr show --name "${ACR_NAME}" --query loginServer -o tsv)"
FULL_IMAGE_NAME="${ACR_LOGIN_SERVER}/${ACR_NAME}:latest"

echo "ACR Login Server : ${ACR_LOGIN_SERVER}"
echo "Full Image Name  : ${FULL_IMAGE_NAME}"

echo
echo "=== STEP 5: Build Docker image from existing Dockerfile ==="
cd "${APP_DIR}"
docker build -t "${LOCAL_IMAGE}" .

echo
echo "=== STEP 6: Tag image for ACR ==="
docker tag "${LOCAL_IMAGE}" "${FULL_IMAGE_NAME}"

echo
echo "=== STEP 7: Push image to ACR ==="
docker push "${FULL_IMAGE_NAME}"

echo
echo "=== STEP 8: Verify repository and tag ==="
az acr repository list \
  --name "${ACR_NAME}" \
  --output table

az acr repository show-tags \
  --name "${ACR_NAME}" \
  --repository "${ACR_NAME}" \
  --output table

echo
echo "=== SUCCESS ==="
echo "ACR ${ACR_NAME} is available in ${LOCATION} with SKU ${ACR_SKU}."
echo "Image ${FULL_IMAGE_NAME} has been built and pushed successfully."
```

## Runbook
### Prerequisites
- Azure CLI must be installed and authenticated on the `azure-client` host. [learn.microsoft](https://learn.microsoft.com/en-us/azure/container-registry/container-registry-get-started-azure-cli)
- Docker must be installed and working on the `azure-client` host because the image is built locally from `/root/pyapp`. [dev](https://dev.to/s3cloudhub/unlock-the-power-of-azure-cli-push-docker-images-to-acr-with-ease-44e4)
- The directory `/root/pyapp` must exist and contain a valid `Dockerfile`. [youtube](https://www.youtube.com/watch?v=3i8LrJwhboQ)

### Execution Steps
1. Save the script to a file such as `script.sh`. [dev](https://dev.to/s3cloudhub/unlock-the-power-of-azure-cli-push-docker-images-to-acr-with-ease-44e4)
2. Make it executable. [dev](https://dev.to/s3cloudhub/unlock-the-power-of-azure-cli-push-docker-images-to-acr-with-ease-44e4)
3. Run it from the `azure-client` host. [dev](https://dev.to/s3cloudhub/unlock-the-power-of-azure-cli-push-docker-images-to-acr-with-ease-44e4)

```bash
vi script.sh
chmod +x script.sh
./script.sh
```

### What the Script Does
1. Verifies Azure authentication and dynamically discovers the first available resource group from the current subscription context. [learn.microsoft](https://learn.microsoft.com/en-us/azure/container-registry/container-registry-get-started-azure-cli)
2. Validates that `/root/pyapp` exists and contains the `Dockerfile` required by the task. [youtube](https://www.youtube.com/watch?v=3i8LrJwhboQ)
3. Creates the ACR `devopsacr1923` in `eastus` with `Basic` SKU if it does not already exist. [learn.microsoft](https://learn.microsoft.com/en-us/azure/container-registry/container-registry-get-started-azure-cli)
4. Logs in to ACR using `az acr login` so Docker can push images to the registry. [dev](https://dev.to/s3cloudhub/unlock-the-power-of-azure-cli-push-docker-images-to-acr-with-ease-44e4)
5. Builds the local image from `/root/pyapp` with the tag `devopsacr1923:latest`. [youtube](https://www.youtube.com/watch?v=3i8LrJwhboQ)
6. Retrieves the ACR login server dynamically and tags the image as `devopsacr1923.azurecr.io/devopsacr1923:latest`. [qiita](https://qiita.com/turupon/items/88ca03fe2668d8ad4498)
7. Pushes the image to ACR and verifies that the repository exists and that the `latest` tag is present. [youtube](https://www.youtube.com/watch?v=3i8LrJwhboQ)

### Validation Commands
The following commands can be used independently after execution to confirm the result: [learn.microsoft](https://learn.microsoft.com/en-us/cli/azure/acr?view=azure-cli-latest)

```bash
az acr show --name devopsacr1923 -o table
az acr repository list --name devopsacr1923 -o table
az acr repository show-tags --name devopsacr1923 --repository devopsacr1923 -o table
```

### Expected Result
The task is complete when all of the following are true: [learn.microsoft](https://learn.microsoft.com/en-us/azure/container-registry/container-registry-get-started-azure-cli)

- An ACR named `devopsacr1923` exists in `East US`. [learn.microsoft](https://learn.microsoft.com/en-us/azure/container-registry/container-registry-get-started-azure-cli)
- The ACR SKU is `Basic`. [learn.microsoft](https://learn.microsoft.com/en-us/azure/container-registry/container-registry-get-started-azure-cli)
- The Docker image has been built from `/root/pyapp`. [youtube](https://www.youtube.com/watch?v=3i8LrJwhboQ)
- The repository `devopsacr1923` exists inside the registry. [dev](https://dev.to/s3cloudhub/unlock-the-power-of-azure-cli-push-docker-images-to-acr-with-ease-44e4)
- The tag `latest` is visible under that repository. [youtube](https://www.youtube.com/watch?v=3i8LrJwhboQ)
