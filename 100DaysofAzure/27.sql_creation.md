# Runbook and Documentation: Dynamic OTS for Azure SQL Database Deployment

## Overview
This document provides a dynamic OTS script and runbook for creating a publicly accessible Azure SQL Database named `devops-sqldb` on an Azure SQL server named `devops-server-13327` in `westus`. The required compute tier is `Basic`, backup storage redundancy must be locally redundant, the maximum database size must be `2 GB`, and the database must be verified in a ready or online state before task completion. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/single-database-create-quickstart?view=azuresql)

## Dynamic OTS Script
The following script dynamically discovers the active resource group from the current Azure CLI context, prompts for a secure SQL admin password if not already set, creates the SQL server, opens public access through firewall rules, creates the database with the required sizing and redundancy options, and waits until the database reports a ready or online state. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/automated-backups-change-settings?view=azuresql)

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "=== STEP 0: Azure login ==="
# showcreds   # uncomment if your lab requires it
az account show >/dev/null 2>&1 || az login --use-device-code

echo
echo "=== STEP 1: Dynamic context discovery ==="
RG="$(az group list --query '[0].name' -o tsv)"
LOCATION="westus"
SERVER_NAME="devops-server-13327"
DB_NAME="devops-sqldb"
ADMIN_USER="devops-admin"
SERVICE_OBJECTIVE="Basic"
MAX_SIZE="2GB"
BACKUP_REDUNDANCY="Local"

if [[ -z "${RG}" ]]; then
  echo "ERROR: No resource group found in current subscription context."
  exit 1
fi

if [[ -z "${SQL_ADMIN_PASSWORD:-}" ]]; then
  read -rsp "Enter SQL admin password for ${ADMIN_USER}: " SQL_ADMIN_PASSWORD
  echo
fi

if [[ -z "${SQL_ADMIN_PASSWORD}" ]]; then
  echo "ERROR: SQL admin password cannot be empty."
  exit 1
fi

echo "Resource Group      : ${RG}"
echo "Location            : ${LOCATION}"
echo "SQL Server          : ${SERVER_NAME}"
echo "Database            : ${DB_NAME}"
echo "Admin User          : ${ADMIN_USER}"
echo "Service Objective   : ${SERVICE_OBJECTIVE}"
echo "Max Size            : ${MAX_SIZE}"
echo "Backup Redundancy   : ${BACKUP_REDUNDANCY}"

echo
echo "=== STEP 2: Create SQL server if it does not exist ==="
if az sql server show --resource-group "${RG}" --name "${SERVER_NAME}" >/dev/null 2>&1; then
  echo "SQL server ${SERVER_NAME} already exists. Skipping create."
else
  az sql server create \
    --resource-group "${RG}" \
    --name "${SERVER_NAME}" \
    --location "${LOCATION}" \
    --admin-user "${ADMIN_USER}" \
    --admin-password "${SQL_ADMIN_PASSWORD}" \
    -o table
fi

echo
echo "=== STEP 3: Ensure public access firewall rules exist ==="
AZURE_RULE_EXISTS="$(az sql server firewall-rule list \
  --resource-group "${RG}" \
  --server "${SERVER_NAME}" \
  --query "[?name=='AllowAllAzureIPs'].name | [0]" -o tsv)"

if [[ -z "${AZURE_RULE_EXISTS}" ]]; then
  az sql server firewall-rule create \
    --resource-group "${RG}" \
    --server "${SERVER_NAME}" \
    --name "AllowAllAzureIPs" \
    --start-ip-address 0.0.0.0 \
    --end-ip-address 0.0.0.0 \
    -o table
else
  echo "Firewall rule AllowAllAzureIPs already exists."
fi

CLIENT_IP="$(curl -s https://ifconfig.me || true)"
if [[ -n "${CLIENT_IP}" ]]; then
  CLIENT_RULE_EXISTS="$(az sql server firewall-rule list \
    --resource-group "${RG}" \
    --server "${SERVER_NAME}" \
    --query "[?name=='AllowCurrentClientIP'].name | [0]" -o tsv)"

  if [[ -z "${CLIENT_RULE_EXISTS}" ]]; then
    az sql server firewall-rule create \
      --resource-group "${RG}" \
      --server "${SERVER_NAME}" \
      --name "AllowCurrentClientIP" \
      --start-ip-address "${CLIENT_IP}" \
      --end-ip-address "${CLIENT_IP}" \
      -o table
  else
    echo "Firewall rule AllowCurrentClientIP already exists."
  fi
else
  echo "Could not determine current public client IP. Skipping client firewall rule."
fi

echo
echo "=== STEP 4: Create SQL database if it does not exist ==="
if az sql db show --resource-group "${RG}" --server "${SERVER_NAME}" --name "${DB_NAME}" >/dev/null 2>&1; then
  echo "Database ${DB_NAME} already exists. Skipping create."
else
  az sql db create \
    --resource-group "${RG}" \
    --server "${SERVER_NAME}" \
    --name "${DB_NAME}" \
    --service-objective "${SERVICE_OBJECTIVE}" \
    --max-size "${MAX_SIZE}" \
    --backup-storage-redundancy "${BACKUP_REDUNDANCY}" \
    -o table
fi

echo
echo "=== STEP 5: Wait for database to become ready ==="
for i in {1..30}; do
  DB_STATUS="$(az sql db show \
    --resource-group "${RG}" \
    --server "${SERVER_NAME}" \
    --name "${DB_NAME}" \
    --query status -o tsv)"

  echo "Current database status: ${DB_STATUS}"

  if [[ "${DB_STATUS}" == "Online" || "${DB_STATUS}" == "Ready" ]]; then
    break
  fi

  sleep 20
done

FINAL_STATUS="$(az sql db show \
  --resource-group "${RG}" \
  --server "${SERVER_NAME}" \
  --name "${DB_NAME}" \
  --query status -o tsv)"

if [[ "${FINAL_STATUS}" != "Online" && "${FINAL_STATUS}" != "Ready" ]]; then
  echo "ERROR: Database did not reach Ready/Online state. Final status: ${FINAL_STATUS}"
  exit 1
fi

echo
echo "=== STEP 6: Verification ==="
az sql server show \
  --resource-group "${RG}" \
  --name "${SERVER_NAME}" \
  -o table

az sql db show \
  --resource-group "${RG}" \
  --server "${SERVER_NAME}" \
  --name "${DB_NAME}" \
  --query "{name:name,status:status,location:location,currentServiceObjectiveName:currentServiceObjectiveName,maxSizeBytes:maxSizeBytes}" \
  -o table

echo
echo "=== SUCCESS ==="
echo "Azure SQL Server ${SERVER_NAME} and database ${DB_NAME} are configured in ${LOCATION}."
echo "Database status is ${FINAL_STATUS}."
```

## Runbook
### Prerequisites
- Azure CLI must be installed and authenticated on the `azure-client` host. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/single-database-create-quickstart?view=azuresql)
- The active subscription must already contain a usable resource group because the script discovers the resource group dynamically from the current CLI context. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/single-database-create-quickstart?view=azuresql)
- A secure password must be provided for the SQL admin account `devops-admin`. [dotnetthailand](https://www.dotnetthailand.com/storage/azure-sql-database/manage-azure-sql-database-with-azure-cli/)

### Execution Steps
1. Save the script to a file such as `script.sh`. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/single-database-create-quickstart?view=azuresql)
2. Make it executable. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/single-database-create-quickstart?view=azuresql)
3. Run it from `azure-client`. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/single-database-create-quickstart?view=azuresql)
4. Enter a strong password when prompted, or export `SQL_ADMIN_PASSWORD` before running the script. [dotnetthailand](https://www.dotnetthailand.com/storage/azure-sql-database/manage-azure-sql-database-with-azure-cli/)

```bash
vi script.sh
chmod +x script.sh
./script.sh
```

Or run it with an environment variable:

```bash
export SQL_ADMIN_PASSWORD='YourStrongPasswordHere!'
./script.sh
```

### What the Script Does
1. Verifies Azure CLI login and dynamically discovers the first available resource group in the active subscription. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/single-database-create-quickstart?view=azuresql)
2. Creates the Azure SQL server `devops-server-13327` in `westus` with admin user `devops-admin` if it does not already exist. [youtube](https://www.youtube.com/watch?v=z_82uWtCQ7g)
3. Adds a firewall rule for Azure services and a client-IP firewall rule when the client public IP can be detected, which supports public accessibility for the SQL server. [dotnetthailand](https://www.dotnetthailand.com/storage/azure-sql-database/manage-azure-sql-database-with-azure-cli/)
4. Creates the database `devops-sqldb` with `Basic` service objective, `2GB` maximum size, and `Local` backup storage redundancy if it does not already exist. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/automated-backups-change-settings?view=azuresql)
5. Polls the database status until it reports `Online` or `Ready`, which satisfies the requirement to confirm the database is in a ready state before submission. [stackoverflow](https://stackoverflow.com/questions/57884158/when-is-azure-sql-ready-to-receive-queries)
6. Displays a verification summary for the server and database. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/single-database-create-quickstart?view=azuresql)

### Validation Commands
Use the following commands after the script completes to validate the deployment: [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/automated-backups-change-settings?view=azuresql)


- Azure SQL Database `devops-sqldb` exists on that server. [youtube](https://www.youtube.com/watch?v=z_82uWtCQ7g)
- The service objective is `Basic`. [learn.microsoft](https://learn.microsoft.com/en-us/azure/azure-sql/database/single-database-create-quickstart?view=azuresql)

## Notes
The script deliberately keeps the task-defined identifiers such as the server name, database name, location, admin username, and database sizing fixed because these are explicit requirements. It dynamically discovers the resource group and optionally the current client public IP to minimize environment-specific hardcoding while still preserving the exact configuration requested by the task.
