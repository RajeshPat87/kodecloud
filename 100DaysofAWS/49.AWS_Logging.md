# Log Aggregation Setup: Complete Technical Documentation

This document details the design, infrastructure layout, network routing, IAM policies, and execution steps for the automated log aggregation setup built for **xfusion-priv-vpc**.

---

## Technical Overview

The objective of this architecture is to collect local system logs (`/var/log/boots.log`) from an isolated EC2 instance in a private VPC, securely forward them across an internal VPC Peering connection to a public-facing EC2 instance, and then stream those logs to an AWS S3 bucket.

### Architecture Highlights

* **Zero Direct Internet Access for Private Workloads**: The private instance remains entirely isolated from public ingress/egress.
* **VPC Peering Interconnect**: Traffic between private and public instances routes strictly over AWS internal backbone networks using private IPv4 addresses.
* **IAM Instance Profiles**: S3 write operations use short-term IAM credentials assigned to the public EC2 instance via an IAM role (`xfusion-s3-role`), avoiding hardcoded API keys.
* **Automated Sync Pipeline**: Standard `cron` scheduling ensures continuous file delivery across network boundaries.

## IAM Role Policy Configuration

### 1. Trust Policy (`AssumeRole`)

Allows EC2 instances to assume the role via AWS Security Token Service (STS):

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {
        "Service": "ec2.amazonaws.com"
      },
      "Action": "sts:AssumeRole"
    }
  ]
}

```

### 2. S3 Permissions Policy (`xfusion-s3-put-policy`)

Grants scoped `PutObject` permissions restricted strictly to the designated S3 log path:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "s3:PutObject",
      "Resource": "arn:aws:s3:::xfusion-s3-logs-8470/*"
    }
  ]
}

```

## End-to-End Execution Script (`ots.sh`)

This script includes idempotency checks for existing VPCs, IGWs, Peering connections, IAM profiles, and Security Group ingress rules.

```bash
#!/bin/bash
set -e

# ==========================================
# CONFIGURATION VARIABLES
# ==========================================
REGION="us-east-1"

PRIV_VPC_NAME="xfusion-priv-vpc"
PRIV_SUBNET_NAME="xfusion-priv-subnet"
PRIV_RT_NAME="xfusion-priv-rt"
PRIV_EC2_NAME="xfusion-priv-ec2"

PUB_VPC_NAME="xfusion-pub-vpc"
PUB_SUBNET_NAME="xfusion-pub-subnet"
PUB_RT_NAME="xfusion-pub-rt"
PUB_IGW_NAME="xfusion-pub-igw"
PUB_EC2_NAME="xfusion-pub-ec2"

PUB_VPC_CIDR="10.1.0.0/16"
PUB_SUBNET_CIDR="10.1.1.0/24"

KEY_NAME="xfusion-key"
KEY_PATH="/root/.ssh/xfusion-key.pem"

PEERING_NAME="xfusion-vpc-peering"
S3_BUCKET_NAME="xfusion-s3-logs-8470"
IAM_ROLE_NAME="xfusion-s3-role"
IAM_PROFILE_NAME="xfusion-s3-profile"

export AWS_DEFAULT_REGION=$REGION

chmod 400 "$KEY_PATH" 2>/dev/null || true

# ==========================================
# 1. FETCH PRIVATE VPC DETAILS
# ==========================================
echo "--> Fetching Private VPC details..."
PRIV_VPC_ID=$(aws ec2 describe-vpcs --filters "Name=tag:Name,Values=$PRIV_VPC_NAME" --query "Vpcs[0].VpcId" --output text)
PRIV_VPC_CIDR=$(aws ec2 describe-vpcs --vpc-ids "$PRIV_VPC_ID" --query "Vpcs[0].CidrBlock" --output text)
PRIV_SUBNET_ID=$(aws ec2 describe-subnets --filters "Name=tag:Name,Values=$PRIV_SUBNET_NAME" --query "Subnets[0].SubnetId" --output text)
PRIV_RT_ID=$(aws ec2 describe-route-tables --filters "Name=tag:Name,Values=$PRIV_RT_NAME" --query "RouteTables[0].RouteTableId" --output text)
PRIV_EC2_IP=$(aws ec2 describe-instances --filters "Name=tag:Name,Values=$PRIV_EC2_NAME" "Name=instance-state-name,Values=running" --query "Reservations[0].Instances[0].PrivateIpAddress" --output text)

# ==========================================
# 2. PROVISION PUBLIC VPC & NETWORKING
# ==========================================
echo "--> Setting up Public VPC..."
PUB_VPC_ID=$(aws ec2 describe-vpcs --filters "Name=tag:Name,Values=$PUB_VPC_NAME" --query "Vpcs[0].VpcId" --output text)
if [ "$PUB_VPC_ID" == "None" ] || [ -z "$PUB_VPC_ID" ]; then
    PUB_VPC_ID=$(aws ec2 create-vpc --cidr-block "$PUB_VPC_CIDR" --query "Vpc.VpcId" --output text)
    aws ec2 create-tags --resources "$PUB_VPC_ID" --tags Key=Name,Value="$PUB_VPC_NAME"
    aws ec2 modify-vpc-attribute --vpc-id "$PUB_VPC_ID" --enable-dns-hostnames '{"Value": true}'
fi

PUB_SUBNET_ID=$(aws ec2 describe-subnets --filters "Name=tag:Name,Values=$PUB_SUBNET_NAME" --query "Subnets[0].SubnetId" --output text)
if [ "$PUB_SUBNET_ID" == "None" ] || [ -z "$PUB_SUBNET_ID" ]; then
    PUB_SUBNET_ID=$(aws ec2 create-subnet --vpc-id "$PUB_VPC_ID" --cidr-block "$PUB_SUBNET_CIDR" --query "Subnet.SubnetId" --output text)
    aws ec2 create-tags --resources "$PUB_SUBNET_ID" --tags Key=Name,Value="$PUB_SUBNET_NAME"
    aws ec2 modify-subnet-attribute --subnet-id "$PUB_SUBNET_ID" --map-public-ip-on-launch
fi

ATTACHED_IGW=$(aws ec2 describe-internet-gateways --filters "Name=attachment.vpc-id,Values=$PUB_VPC_ID" --query "InternetGateways[0].InternetGatewayId" --output text)
if [ "$ATTACHED_IGW" != "None" ] && [ -n "$ATTACHED_IGW" ]; then
    PUB_IGW_ID="$ATTACHED_IGW"
else
    PUB_IGW_ID=$(aws ec2 describe-internet-gateways --filters "Name=tag:Name,Values=$PUB_IGW_NAME" --query "InternetGateways[0].InternetGatewayId" --output text)
    if [ "$PUB_IGW_ID" == "None" ] || [ -z "$PUB_IGW_ID" ]; then
        PUB_IGW_ID=$(aws ec2 create-internet-gateway --query "InternetGateway.InternetGatewayId" --output text)
        aws ec2 create-tags --resources "$PUB_IGW_ID" --tags Key=Name,Value="$PUB_IGW_NAME"
    fi
    aws ec2 attach-internet-gateway --vpc-id "$PUB_VPC_ID" --internet-gateway-id "$PUB_IGW_ID" 2>/dev/null || true
fi

PUB_RT_ID=$(aws ec2 describe-route-tables --filters "Name=tag:Name,Values=$PUB_RT_NAME" --query "RouteTables[0].RouteTableId" --output text)
if [ "$PUB_RT_ID" == "None" ] || [ -z "$PUB_RT_ID" ]; then
    PUB_RT_ID=$(aws ec2 create-route-table --vpc-id "$PUB_VPC_ID" --query "RouteTable.RouteTableId" --output text)
    aws ec2 create-tags --resources "$PUB_RT_ID" --tags Key=Name,Value="$PUB_RT_NAME"
    aws ec2 create-route --route-table-id "$PUB_RT_ID" --destination-cidr-block "0.0.0.0/0" --gateway-id "$PUB_IGW_ID" 2>/dev/null || true
    aws ec2 associate-route-table --subnet-id "$PUB_SUBNET_ID" --route-table-id "$PUB_RT_ID" 2>/dev/null || true
fi

# ==========================================
# 3. VPC PEERING SETUP
# ==========================================
echo "--> Configuring VPC Peering..."
PEERING_ID=$(aws ec2 describe-vpc-peering-connections --filters "Name=tag:Name,Values=$PEERING_NAME" "Name=status-code,Values=active,pending-acceptance" --query "VpcPeeringConnections[0].VpcPeeringConnectionId" --output text)
if [ "$PEERING_ID" == "None" ] || [ -z "$PEERING_ID" ]; then
    PEERING_ID=$(aws ec2 create-vpc-peering-connection --vpc-id "$PRIV_VPC_ID" --peer-vpc-id "$PUB_VPC_ID" --query "VpcPeeringConnection.VpcPeeringConnectionId" --output text)
    aws ec2 create-tags --resources "$PEERING_ID" --tags Key=Name,Value="$PEERING_NAME"
    aws ec2 accept-vpc-peering-connection --vpc-peering-connection-id "$PEERING_ID" 2>/dev/null || true
else
    aws ec2 accept-vpc-peering-connection --vpc-peering-connection-id "$PEERING_ID" 2>/dev/null || true
fi

aws ec2 create-route --route-table-id "$PRIV_RT_ID" --destination-cidr-block "$PUB_VPC_CIDR" --vpc-peering-connection-id "$PEERING_ID" 2>/dev/null || true
aws ec2 create-route --route-table-id "$PUB_RT_ID" --destination-cidr-block "$PRIV_VPC_CIDR" --vpc-peering-connection-id "$PEERING_ID" 2>/dev/null || true

# ==========================================
# 4. S3 & IAM RESOURCES
# ==========================================
echo "--> Configuring Storage & Identity..."
if ! aws s3api head-bucket --bucket "$S3_BUCKET_NAME" 2>/dev/null; then
    aws s3api create-bucket --bucket "$S3_BUCKET_NAME"
    aws s3api put-public-access-block --bucket "$S3_BUCKET_NAME" --public-access-block-configuration "BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true"
fi

if ! aws iam get-role --role-name "$IAM_ROLE_NAME" 2>/dev/null; then
    TRUST_POLICY='{"Version":"2012-10-17","Statement":[{"Effect":"Allow","Principal":{"Service":"ec2.amazonaws.com"},"Action":"sts:AssumeRole"}]}'
    aws iam create-role --role-name "$IAM_ROLE_NAME" --assume-role-policy-document "$TRUST_POLICY"
    
    S3_POLICY="{\"Version\":\"2012-10-17\",\"Statement\":[{\"Effect\":\"Allow\",\"Action\":\"s3:PutObject\",\"Resource\":\"arn:aws:s3:::$S3_BUCKET_NAME/*\"}]}"
    aws iam put-role-policy --role-name "$IAM_ROLE_NAME" --policy-name "xfusion-s3-put-policy" --policy-document "$S3_POLICY"
fi

if ! aws iam get-instance-profile --instance-profile-name "$IAM_PROFILE_NAME" 2>/dev/null; then
    aws iam create-instance-profile --instance-profile-name "$IAM_PROFILE_NAME"
    aws iam add-role-to-instance-profile --instance-profile-name "$IAM_PROFILE_NAME" --role-name "$IAM_ROLE_NAME"
    sleep 10
fi

# ==========================================
# 5. PUBLIC EC2 PROVISIONING
# ==========================================
echo "--> Provisioning Public Instance..."
PUB_EC2_ID=$(aws ec2 describe-instances --filters "Name=tag:Name,Values=$PUB_EC2_NAME" "Name=instance-state-name,Values=running,pending" --query "Reservations[0].Instances[0].InstanceId" --output text)

if [ "$PUB_EC2_ID" == "None" ] || [ -z "$PUB_EC2_ID" ]; then
    AMI_ID=$(aws ssm get-parameters --names /aws/service/canonical/ubuntu/server/22.04/stable/current/amd64/hvm/ebs-gp2/ami-id --query "Parameters[0].Value" --output text)
    
    PUB_EC2_ID=$(aws ec2 run-instances \
        --image-id "$AMI_ID" \
        --instance-type t2.micro \
        --key-name "$KEY_NAME" \
        --subnet-id "$PUB_SUBNET_ID" \
        --iam-instance-profile Name="$IAM_PROFILE_NAME" \
        --tag-specifications "ResourceType=instance,Tags=[{Key=Name,Value=$PUB_EC2_NAME}]" \
        --query "Instances[0].InstanceId" --output text)
        
    aws ec2 wait instance-running --instance-ids "$PUB_EC2_ID"
fi

PUB_EC2_PUB_IP=$(aws ec2 describe-instances --instance-ids "$PUB_EC2_ID" --query "Reservations[0].Instances[0].PublicIpAddress" --output text)
PUB_EC2_PRIV_IP=$(aws ec2 describe-instances --instance-ids "$PUB_EC2_ID" --query "Reservations[0].Instances[0].PrivateIpAddress" --output text)

PUB_SG_ID=$(aws ec2 describe-instances --instance-ids "$PUB_EC2_ID" --query "Reservations[0].Instances[0].SecurityGroups[0].GroupId" --output text)
aws ec2 authorize-security-group-ingress --group-id "$PUB_SG_ID" --protocol tcp --port 22 --cidr 0.0.0.0/0 2>/dev/null || true
aws ec2 authorize-security-group-ingress --group-id "$PUB_SG_ID" --protocol tcp --port 22 --cidr "$PRIV_VPC_CIDR" 2>/dev/null || true

PRIV_EC2_ID=$(aws ec2 describe-instances --filters "Name=tag:Name,Values=$PRIV_EC2_NAME" "Name=instance-state-name,Values=running" --query "Reservations[0].Instances[0].InstanceId" --output text)
PRIV_SG_ID=$(aws ec2 describe-instances --instance-ids "$PRIV_EC2_ID" --query "Reservations[0].Instances[0].SecurityGroups[0].GroupId" --output text)
aws ec2 authorize-security-group-ingress --group-id "$PRIV_SG_ID" --protocol tcp --port 22 --cidr "$PUB_VPC_CIDR" 2>/dev/null || true

until ssh -o StrictHostKeyChecking=no -o ConnectTimeout=5 -i "$KEY_PATH" ubuntu@"$PUB_EC2_PUB_IP" "echo ready" &>/dev/null; do
    sleep 5
done

# ==========================================
# 6. CRON & LOG CONFIGURATION
# ==========================================
echo "--> Setting up cron jobs..."
ssh -o StrictHostKeyChecking=no -i "$KEY_PATH" ubuntu@"$PUB_EC2_PUB_IP" << EOF
sudo apt-get update -y && sudo apt-get install -y awscli
mkdir -p /home/ubuntu/logs
(crontab -l 2>/dev/null | grep -v 's3://'; echo "* * * * * aws s3 cp /home/ubuntu/logs/boots.log s3://$S3_BUCKET_NAME/$PRIV_VPC_NAME/boot/boots.log") | crontab -
EOF

scp -o StrictHostKeyChecking=no -i "$KEY_PATH" "$KEY_PATH" ubuntu@"$PUB_EC2_PUB_IP":/home/ubuntu/key.pem
ssh -o StrictHostKeyChecking=no -i "$KEY_PATH" ubuntu@"$PUB_EC2_PUB_IP" "chmod 400 /home/ubuntu/key.pem"

ssh -o StrictHostKeyChecking=no -i "$KEY_PATH" ubuntu@"$PUB_EC2_PUB_IP" \
    "scp -i /home/ubuntu/key.pem /home/ubuntu/key.pem ubuntu@$PRIV_EC2_IP:/home/ubuntu/key.pem"
ssh -o StrictHostKeyChecking=no -i "$KEY_PATH" ubuntu@"$PUB_EC2_PUB_IP" \
    "ssh -i /home/ubuntu/key.pem ubuntu@$PRIV_EC2_IP 'chmod 400 /home/ubuntu/key.pem'"

ssh -o StrictHostKeyChecking=no -i "$KEY_PATH" ubuntu@"$PUB_EC2_PUB_IP" \
    "ssh -i /home/ubuntu/key.pem ubuntu@$PRIV_EC2_IP \"(crontab -l 2>/dev/null | grep -v 'boots.log'; echo '* * * * * scp -o StrictHostKeyChecking=no -i /home/ubuntu/key.pem /var/log/boots.log ubuntu@$PUB_EC2_PRIV_IP:/home/ubuntu/logs/boots.log') | crontab -\""

ssh -o StrictHostKeyChecking=no -i "$KEY_PATH" ubuntu@"$PUB_EC2_PUB_IP" "rm -f /home/ubuntu/key.pem"

echo "Setup completed successfully."

```

## Validation & Troubleshooting Guide

### 1. Primary Health Checks

Run these checks directly from the `aws-client` host:

```bash
# Obtain Public EC2 IP Address
PUB_IP=$(aws ec2 describe-instances --filters "Name=tag:Name,Values=xfusion-pub-ec2" "Name=instance-state-name,Values=running" --query "Reservations[0].Instances[0].PublicIpAddress" --output text)

# Step 1: Verify file existence on public host
ssh -i /root/.ssh/xfusion-key.pem ubuntu@$PUB_IP "ls -la /home/ubuntu/logs/boots.log"

# Step 2: Read contents on public host
ssh -i /root/.ssh/xfusion-key.pem ubuntu@$PUB_IP "cat /home/ubuntu/logs/boots.log"

# Step 3: Verify S3 bucket upload
aws s3 ls s3://xfusion-s3-logs-8470/xfusion-priv-vpc/boot/boots.log

```

### 2. Common Issues & Resolution Matrix

| Symptom | Cause | Resolution Command / Action |
| --- | --- | --- |
| `ls: cannot access '/home/ubuntu/logs/boots.log'` | Private host cannot reach Public host on Port 22 | Check security group ingress rule on `xfusion-pub-ec2` allowing CIDR `10.10.0.0/16`. |
| `ping` packet loss across VPCs | Missing Peering route entries | Verify routes on `xfusion-priv-rt` and `xfusion-pub-rt` targeting `PEERING_ID`. |
| `aws s3 cp` Permission Denied | IAM role missing or pending propagation | Verify `xfusion-s3-profile` is attached to `xfusion-pub-ec2` using `aws ec2 describe-instances`. |
| Cron job not executing | Misconfigured crontab on target host | Run `crontab -l` on both hosts to verify formatting and binary path availability (`/usr/bin/aws`). |
