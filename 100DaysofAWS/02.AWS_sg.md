## Concept

A **security group (SG)** is a stateful virtual firewall attached to ENIs/instances. "Stateful" means return traffic for an allowed inbound flow is automatically permitted — you only define **inbound** rules here. Every SG lives inside **one VPC** and is **regional**. New SGs start with **no inbound rules** (deny all in) and an **allow-all outbound** rule by default.

This task needs one SG in the **default VPC** with two inbound rules: HTTP (80) and SSH (22), both open to `0.0.0.0/0`.

## OTS (CLI, one block)

```bash
REGION=us-east-1

# 1. Get the default VPC ID
VPC_ID=$(aws ec2 describe-vpcs \
  --filters "Name=isDefault,Values=true" \
  --query 'Vpcs[0].VpcId' --output text --region $REGION)
echo "Default VPC: $VPC_ID"

# 2. Create the security group
SG_ID=$(aws ec2 create-security-group \
  --group-name xfusion-sg \
  --description "Security group for Nautilus App Servers" \
  --vpc-id $VPC_ID \
  --region $REGION \
  --query 'GroupId' --output text)
echo "SG: $SG_ID"

# 3. Inbound HTTP (80)
aws ec2 authorize-security-group-ingress \
  --group-id $SG_ID --protocol tcp --port 80 --cidr 0.0.0.0/0 --region $REGION

# 4. Inbound SSH (22)
aws ec2 authorize-security-group-ingress \
  --group-id $SG_ID --protocol tcp --port 22 --cidr 0.0.0.0/0 --region $REGION
```

**Verify:**
```bash
aws ec2 describe-security-groups --group-ids $SG_ID --region us-east-1 \
  --query 'SecurityGroups[0].{Name:GroupName,Desc:Description,VPC:VpcId,Ingress:IpPermissions[].{Port:FromPort,CIDR:IpRanges[0].CidrIp}}'
```
Expect ports 80 and 22, each with `0.0.0.0/0`.

### Gotchas

- **Exact description match:** graders often check the description string literally. Type `Security group for Nautilus App Servers` verbatim.
- **Default VPC required:** if you pick the wrong VPC (or a non-default one), it fails. The CLI filter `isDefault=true` guarantees the right one.
- **Type dropdown in console** auto-sets protocol/port — selecting `HTTP` fills TCP/80, `SSH` fills TCP/22. Just set the source to `0.0.0.0/0`.
- **Region:** pin `us-east-1` everywhere.
