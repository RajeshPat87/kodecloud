Use this command on **Application Server 3**:

```bash
docker run -d --name nginx_3 nginx:alpine
```

## Verify
Check that the container is running:

```bash
docker ps
```

If needed, pull first:

```bash
docker pull nginx:alpine
docker run -d --name nginx_3 nginx:alpine
```

This matches the task requirement: create a container named `nginx_3` from the `nginx:alpine` image and keep it in a running state. [hub.docker](https://hub.docker.com/_/nginx)
