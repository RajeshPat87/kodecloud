## OTS — run on jump host as thor

```bash
#!/usr/bin/env bash
# jump host — per-server file copy using when conditionals on ansible_nodename
set -e

cd /home/thor/ansible

[ -f ansible.cfg ] || cat > ansible.cfg <<'EOF'
[defaults]
host_key_checking = False
inventory = inventory
EOF

cat > playbook.yml <<'EOF'
---
- hosts: all
  become: true
  tasks:
    - name: Copy blog.txt to App Server 1
      ansible.builtin.copy:
        src: /usr/src/devops/blog.txt
        dest: /opt/devops/blog.txt
        owner: tony
        group: tony
        mode: '0655'
      when: ansible_nodename == "stapp01"

    - name: Copy story.txt to App Server 2
      ansible.builtin.copy:
        src: /usr/src/devops/story.txt
        dest: /opt/devops/story.txt
        owner: steve
        group: steve
        mode: '0655'
      when: ansible_nodename == "stapp02"

    - name: Copy media.txt to App Server 3
      ansible.builtin.copy:
        src: /usr/src/devops/media.txt
        dest: /opt/devops/media.txt
        owner: banner
        group: banner
        mode: '0655'
      when: ansible_nodename == "stapp03"
EOF

echo "== playbook.yml =="; cat playbook.yml
```

## Why each piece

**`hosts: all`** — required by the note. The play runs on every server, but each task's `when` decides whether it actually executes there.

**`when: ansible_nodename == "stappNN"`** — this is the whole point of the task (Ansible conditionals). The play visits all three hosts; on stapp01 only the blog.txt task passes its `when` and runs, the other two skip; on stapp02 only story.txt runs; and so on. That's how one play with `hosts: all` produces per-server results.

**`ansible_nodename`** — the note explicitly suggests this variable. It comes from gathered facts (fact-gathering is on by default, so no extra config). It's the OS-reported hostname, which matches `stapp01/02/03`.

**`copy` src/dest** — pushes each file from the jump host's `/usr/src/devops/` to the target's `/opt/devops/`. Each with its owner/group (tony/steve/banner) and `mode: '0655'`.

**`become: true`** — `/opt/devops` and setting ownership need root.

## Watch-outs

- **`when` value must match `ansible_nodename` exactly** — run Step 1 first. If `ansible_nodename` returns something other than `stapp01` (e.g. an FQDN), your `when` won't match and the task silently skips (file never copied). Match the actual string.
- **`hosts: all` is mandatory** — the note requires it. Don't use per-host plays here; the task is specifically demonstrating `when`.
- **Fact gathering must be on** — `ansible_nodename` is a gathered fact; it's on by default. Don't set `gather_facts: false`, or the variable won't exist and every `when` fails.
- **`/opt/devops` must exist** — `copy` creates the file but not missing parent dirs. If the run errors "Destination directory /opt/devops does not exist", add a `file: path: /opt/devops state: directory` task (also `when`-gated, or ungated with `become`). In these labs the dir usually exists.
- **`mode: '0655'` quoted** → `-rw-r--r-x`.
- **owner/group match the server** — tony→stapp01, steve→stapp02, banner→stapp03. Don't mix.
- Files exact: playbook `/home/thor/ansible/playbook.yml`; sources in `/usr/src/devops/` on the jump host.
