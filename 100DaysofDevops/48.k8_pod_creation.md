Create the pod with either a YAML manifest or a one-liner. The cleanest way is YAML, with the exact pod name, image tag, label, and container name you specified. [nbtechsupport.co](https://www.nbtechsupport.co.in/2021/05/create-pods-in-kubernetes-cluster.html)

## YAML
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: pod-httpd
  labels:
    app: httpd_app
spec:
  containers:
    - name: httpd-container
      image: httpd:latest
```

## Apply it
```bash
kubectl apply -f pod-httpd.yaml
kubectl get pod pod-httpd --show-labels
```

## One-liner alternative
```bash
kubectl run pod-httpd --image=httpd:latest --restart=Never --labels=app=httpd_app --overrides='{"apiVersion":"v1","spec":{"containers":[{"name":"httpd-container","image":"httpd:latest"}]}}'
```
