Use `docker commit` to create the image from the running container. This will capture `ubuntu_latest` as a new image and tag it as `official:datacenter`. [observeinc](https://www.observeinc.com/blog/create-docker-image)

## Command

```bash
docker commit ubuntu_latest official:datacenter
```

## Verify

```bash
docker images | grep official
```
