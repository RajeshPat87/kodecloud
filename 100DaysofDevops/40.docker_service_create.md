From the **host**, you don’t usually list “services” directly inside a normal container; you run commands **inside the container** using `docker exec`. For Apache, the most common checks are `service apache2 status` or `service --status-all` executed through `docker exec`. [stackoverflow](https://stackoverflow.com/questions/32367727/how-to-get-services-and-its-status-inside-the-docker-containers)

## Commands from host

```bash
docker exec -it kkloud service --status-all
```

or for Apache specifically:

```bash
docker exec -it kkloud service apache2 status
```

If you want to see processes instead of init services, use:

```bash
docker exec -it kkloud ps aux
```

## Notes

- `docker ps` shows containers, not internal services. [spacelift](https://spacelift.io/blog/docker-list-containers)
- `docker exec` runs the command inside the container from the host. [stackoverflow](https://stackoverflow.com/questions/32367727/how-to-get-services-and-its-status-inside-the-docker-containers)
