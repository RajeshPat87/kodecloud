The image is also mistyped as `redis:alpin`, but the immediate blocker is the missing ConfigMap mount, which keeps the pod in `ContainerCreating`. [chris-young](https://chris-young.net/59-100-troubleshoot-deployment-issues-in-kubernetes/)

## Exact issues
- `redis:alpin` should be `redis:alpine`.
- `redis-conig` should be `redis-config`.
- The CPU request is set correctly as `300m`, so that part is fine. [chris-young](https://chris-young.net/59-100-troubleshoot-deployment-issues-in-kubernetes/)
