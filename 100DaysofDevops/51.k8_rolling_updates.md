Use `kubectl set image` to trigger the rolling update, then wait for the rollout to complete. This updates the Deployment named `nginx-deployment` to use `nginx:1.18` and keeps the app available during the change. [kubernetes](https://kubernetes.io/docs/tasks/run-application/update-deployment-rolling/)

## Commands
```bash
kubectl set image deployment/nginx-deployment nginx=nginx:1.18
kubectl rollout status deployment/nginx-deployment
kubectl get pods
```

## Verify
If you want to confirm the image version too:

```bash
kubectl get deployment nginx-deployment -o jsonpath='{.spec.template.spec.containers[0].image}'
```

A successful rollout will show `deployment "nginx-deployment" successfully rolled out`, and all pods should be running afterward. [kubernetes](https://kubernetes.io/docs/tasks/run-application/update-deployment-rolling/)
