## 1. Objective

Create a Jenkins job named **`database-backup`** that:

- Runs `mysqldump` of the `kodekloud_db01` database on **App Server 1 (`stapp01`)**.
- Uses DB credentials: user `kodekloud_roy`, password `asdfgdsd`.
- Names the dump file `db_$(date +%F).sql`.
- Copies the dump to **Storage Server (`ststor01`)** at `/home/natasha/db_backups`.
- Is scheduled to run periodically at **`*/10 * * * *`** (every 10 minutes).
- Is created and managed via **Jenkins CLI + Groovy**, with minimal UI usage.

## 5. Create `database-backup` Job via CLI + Groovy

### 5.1 Groovy script to create/configure job

Create `create-database-backup.groovy` on the Jenkins server:

```bash
cat > create-database-backup.groovy << 'EOF'
import jenkins.model.*
import hudson.model.*
import hudson.triggers.TimerTrigger
import hudson.tasks.Shell

def jenkins = Jenkins.instance

def jobName  = "database-backup"
def cronSpec = "*/10 * * * *"  // EXACT cron as per requirement

// Delete existing job if any
def existing = jenkins.getItem(jobName)
if (existing != null) {
    println "Job '${jobName}' already exists, deleting it first..."
    existing.delete()
}

// Create new Freestyle job
println "Creating job '${jobName}'..."
def job = new hudson.model.FreeStyleProject(jenkins, jobName)
jenkins.add(job, jobName)

// Add periodic trigger
println "Setting build trigger to cron: ${cronSpec}"
def timerTrigger = new TimerTrigger(cronSpec)
job.addTrigger(timerTrigger)

// Shell script for database dump and copy
def shellScript = '''#!/bin/bash
set -e

APP_SERVER="stapp01"
APP_USER="tony"

STORAGE_SERVER="ststor01"
STORAGE_USER="natasha"

DB_NAME="kodekloud_db01"
DB_USER="kodekloud_roy"
DB_PASS="asdfgdsd"

BACKUP_NAME="db_$(date +%F).sql"
REMOTE_BACKUP_DIR="/home/natasha/db_backups"

echo "Starting database backup for ${DB_NAME} from ${APP_SERVER}..."

# Take mysqldump on App Server into /tmp/db_YYYY-MM-DD.sql
ssh ${APP_USER}@${APP_SERVER} "mysqldump -u${DB_USER} -p${DB_PASS} ${DB_NAME} > /tmp/${BACKUP_NAME}"

# Ensure backup directory exists on Storage Server
ssh ${STORAGE_USER}@${STORAGE_SERVER} "mkdir -p ${REMOTE_BACKUP_DIR}"

# Copy dump from App Server to Jenkins server
scp ${APP_USER}@${APP_SERVER}:/tmp/${BACKUP_NAME} /tmp/${BACKUP_NAME}

# Copy dump from Jenkins server to Storage Server
scp /tmp/${BACKUP_NAME} ${STORAGE_USER}@${STORAGE_SERVER}:${REMOTE_BACKUP_DIR}/${BACKUP_NAME}

echo "Database backup '${BACKUP_NAME}' copied to ${STORAGE_SERVER}:${REMOTE_BACKUP_DIR}"
'''

println "Adding shell build step..."
def shellBuilder = new Shell(shellScript)
job.buildersList.clear()
job.buildersList.add(shellBuilder)

// Save job
job.save()

println "Job '${jobName}' created and configured successfully."
EOF
```

Notes:

- Cron expression is exactly `*/10 * * * *`, as required.
- `shellScript` is single-quoted (`'''`) so `$` and `${}` are passed literally to bash.

### 5.2 Run Groovy via CLI to create job

```bash
java -jar jenkins-cli.jar -s http://localhost:8080 -auth 'admin:Adm!n321' groovy = < create-database-backup.groovy
```

Expected output:

```text

Adding shell build step...
```

## 10. Lessons and Reuse

- **Manual vs automated SSH**:
  - Manual SSH uses passwords and host-key prompts.
  - Jenkins job requires key-based SSH (`BatchMode` tests) before it can run non‑interactively.
- **Groovy string handling**:
  - Use **single-quoted triple strings** for shell scripts to avoid `$` being treated as Groovy interpolation.
- **Cron correctness**:
  - For KodeKloud grading, use the **exact string** they specify (`*/10 * * * *`), even if Jenkins suggests `H/10 * * * *`.

You can reuse this documentation as a template for future Jenkins CLI + SSH + cron tasks (e.g., log collection, package installs, other backups).
