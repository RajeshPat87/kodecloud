## OTS — run on jump host as thor

```bash
#!/usr/bin/env bash
# jump host — inventory + playbook: create /opt/webapp.txt with per-host owner
set -e

cd ~/playbook

# 1. inventory: all three app servers; each SSH user doubles as the file owner
cat > inventory <<'EOF'
[app_servers]
stapp01 ansible_host=stapp01 ansible_user=tony   ansible_ssh_pass=Ir0nM@n
stapp02 ansible_host=stapp02 ansible_user=steve  ansible_ssh_pass=Am3ric@
stapp03 ansible_host=stapp03 ansible_user=banner ansible_ssh_pass=BigGr33n

[app_servers:vars]
ansible_connection=ssh
EOF

# 2. cfg so sshpass isn't blocked by host-key checking; sets default inventory
cat > ansible.cfg <<'EOF'
[defaults]
host_key_checking = False
inventory = inventory
EOF

# 3. playbook: blank file, mode 0744, owner/group = each host's ansible_user
cat > playbook.yml <<'EOF'
---
- name: Create /opt/webapp.txt on all app servers
  hosts: app_servers
  become: true
  tasks:
    - name: Create blank file with per-host owner and mode
      ansible.builtin.file:
        path: /opt/webapp.txt
        state: touch
        owner: "{{ ansible_user }}"
        group: "{{ ansible_user }}"
        mode: '0744'
EOF

echo "== inventory =="; cat inventory
echo "== playbook.yml =="; cat playbook.yml
```

## Why each piece

**Per-host owner via `{{ ansible_user }}`** — since each host's SSH user (tony/steve/banner) is exactly the required owner, referencing `ansible_user` makes one task set the right owner on each server automatically. No per-host `when:` conditions needed. Requirement d satisfied cleanly.

**`state: touch`** — creates the blank file (requirement b), idempotent on reruns. Combined with `mode: '0744'` (requirement c) and `owner`/`group` (requirement d), the single `file` task does all four sub-requirements at once.

**`mode: '0744'`** — quoted so YAML treats it as the octal string, not a decimal number. Unquoted `0744` can be misinterpreted; always quote file modes.

**`become: true`** — `/opt` is root-owned, so creating the file and setting ownership needs sudo.

## Watch-outs

- **`mode: '0744'` must be quoted** — unquoted, YAML may read it as octal/decimal oddly and apply the wrong bits. `-rwxr--r--` = owner rwx, group r, other r = 0744.
- **`owner`/`group` require `become: true`** — chown is a root operation; without sudo you get "chown failed: Operation not permitted."
- **`{{ ansible_user }}` resolves per host** — because it's defined per line in the inventory. If you'd instead hardcoded, you'd need three tasks with `when: inventory_hostname == 'stappNN'`. The variable approach is cleaner and less error-prone.
- **Host-key/sshpass block** → handled by `ansible.cfg` (same fix as before).
- **Group name matches** — each user has a primary group of the same name (tony:tony, etc.) on these servers, so `group: "{{ ansible_user }}"` works. If a group didn't exist it'd error, but Nautilus app users have matching groups.
- **Dir is `~/playbook`** this time, not `~/ansible` — inventory `~/playbook/inventory`, playbook `~/playbook/playbook.yml`.
