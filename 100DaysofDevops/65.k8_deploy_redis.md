## Purpose (current Redis lab)

Deploy a **single-Replica Redis instance** on the Kubernetes cluster for testing DB caching, with:

- ConfigMap `my-redis-config` containing `redis-config: "maxmemory 2mb"`.
- Deployment `redis-deployment`:
  - Image: `redis:alpine`
  - Container: `redis-container`
  - Replicas: `1`
  - Resource request: `cpu: "1"`
  - Volumes:
    - `data` (emptyDir) at `/redis-master-data`
    - `redis-config` (ConfigMap) at `/redis-master`
  - Exposed container port: `6379`
- Pod in `Running` and `READY 1/1` state for performance testing. [github](https://github.com/karadHub/100-Days-Of-DevOps/blob/main/Day%2065/Deploy%20Redis%20Deployment%20on%20Kubernetes.md)

## OTS (One-Time Setup) – Redis Lab Only

### 1) Create ConfigMap `my-redis-config`

```bash
cat << 'EOF' > my-redis-config.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: my-redis-config
data:
  redis-config: |
    maxmemory 2mb
EOF

kubectl apply -f my-redis-config.yaml
kubectl get configmap my-redis-config -o yaml
```

### 2) Create Redis deployment `redis-deployment`

```bash
cat << 'EOF' > redis-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: redis-deployment
  labels:
    app: redis
spec:
  replicas: 1
  selector:
    matchLabels:
      app: redis
  template:
    metadata:
      labels:
        app: redis
    spec:
      containers:
        - name: redis-container
          image: redis:alpine
          command:
            - redis-server
            - "/redis-master/redis.conf"
          ports:
            - containerPort: 6379
          resources:
            requests:
              cpu: "1"
          volumeMounts:
            - name: data
              mountPath: /redis-master-data
            - name: redis-config
              mountPath: /redis-master
      volumes:
        - name: data
          emptyDir: {}
        - name: redis-config
          configMap:
            name: my-redis-config
            items:
              - key: redis-config
                path: redis.conf
EOF

kubectl apply -f redis-deployment.yaml
kubectl get deploy redis-deployment
kubectl get pods -l app=redis -o wide
```

## Runbook (Redis lab – logical steps)

### Step 1: ConfigMap creation

1. Apply ConfigMap manifest:

   ```bash
   kubectl apply -f my-redis-config.yaml
   ```

2. Validate:

   ```bash
   kubectl get configmap my-redis-config -o yaml
   ```

   Ensure:

   - `metadata.name: my-redis-config`
   - `data.redis-config` contains `maxmemory 2mb`. [pwittrock.github](https://pwittrock.github.io/docs/tutorials/configuration/configure-redis-using-configmap/)

### Step 2: Deployment creation

1. Apply deployment manifest:

   ```bash
   kubectl apply -f redis-deployment.yaml
   ```

2. Check deployment and pods:

   ```bash
   kubectl get deploy redis-deployment
   kubectl get pods -l app=redis -o wide
   kubectl describe deploy redis-deployment
   ```

   Confirm:

   - `replicas: 1 desired | 1 available`.
   - Labels: `app=redis` for both selector and template.
   - Container:
     - Name `redis-container`
     - Image `redis:alpine`
     - `containerPort: 6379`
     - `resources.requests.cpu: "1"`
   - Volumes:
     - `data` → `emptyDir: {}`
     - `redis-config` → `configMap.name: my-redis-config` with `items: redis-config -> redis.conf`.
   - Volume mounts:
     - `data` at `/redis-master-data`
     - `redis-config` at `/redis-master`.

### Step 3: Runtime and config verification

1. Exec into Redis pod:

   ```bash
   POD_NAME=$(kubectl get pods -l app=redis -o jsonpath='{.items.metadata.name}')
   kubectl exec -it "$POD_NAME" -- sh
   ```

2. Inside the pod:

   ```bash
   # Confirm configuration file
   cat /redis-master/redis.conf

   # Verify maxmemory is applied
   redis-cli CONFIG GET maxmemory

   # Basic health check
   redis-cli ping
   ```

   Expect:

   - `redis.conf` contains `maxmemory 2mb`.
   - `CONFIG GET maxmemory` returns a value around `2097152`.
   - `PING` returns `PONG`. [github](https://github.com/karadHub/100-Days-Of-DevOps/blob/main/Day%2065/Deploy%20Redis%20Deployment%20on%20Kubernetes.md)

3. Exit and check pod status:

   ```bash
   kubectl get pods -l app=redis
   ```

   Pod should be `Running` and `READY 1/1`.

Once those checks pass, the lab’s requirement “Finally, redis-deployment should be up and running” is satisfied.
