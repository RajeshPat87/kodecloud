Use `kubectl rollout undo` to revert `nginx-deployment` to the previous revision, then verify the rollout completes successfully. [kubernetes](https://kubernetes.io/docs/concepts/workloads/controllers/deployment/)

## Commands
```bash
kubectl rollout undo deployment/nginx-deployment
kubectl rollout status deployment/nginx-deployment
kubectl get pods
```

## Optional check
If you want to see revision history first:

```bash
kubectl rollout history deployment/nginx-deployment
```

## What to expect
- `kubectl rollout undo` rolls the deployment back one revision by default.
- `kubectl rollout status` should end with `successfully rolled out`.
- `kubectl get pods` should show the pods back in a running state. [kubernetes](https://kubernetes.io/docs/concepts/workloads/controllers/deployment/)
