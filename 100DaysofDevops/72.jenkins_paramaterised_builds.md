Here’s exactly how to build that simple parameterized job in Jenkins, step by step.

***

## 1. Log in to Jenkins

1. Click the **Jenkins** button on the lab’s top bar.
2. Log in with:
   - Username: `admin`
   - Password: `Adm!n321`.

You’ll be on the Jenkins dashboard.

***

## 2. Create the job `parameterized-job`

1. On the dashboard, click **New Item**.
2. In **Item name**, enter: `parameterized-job`.
3. Select **Freestyle project**.
4. Click **OK**.

You’ll be on the **Configure** page for this job.

***

## 3. Add parameters

### 3.1 String parameter: Stage

In the **General** section:

1. Check **This project is parameterized**.
2. Click **Add Parameter → String Parameter**.
3. Fill in:
   - **Name**: `Stage`
   - **Default Value**: `Build`
   - **Description**: `Pipeline stage name (default: Build)`.

### 3.2 Choice parameter: env

Still under **This project is parameterized**:

1. Click **Add Parameter → Choice Parameter**.
2. Fill in:
   - **Name**: `env`
   - **Choices** (one per line):

     ```text
     Development
     Staging
     Production
     ```

   - **Description**: `Target environment (Development, Staging, Production)`.

Click **Save** once to make sure parameters are stored.

***

## 4. Configure shell command to echo parameters

Now add a **Build Step** that prints both parameter values.

1. Re-open **Configure** if needed.
2. Scroll down to **Build Steps**.
3. Click **Add build step → Execute shell**.
4. Paste the following script:

```bash
#!/bin/bash

echo "Stage parameter value: $Stage"
echo "env parameter value: $env"
```

Explanation:

- Jenkins exposes job parameters as environment variables with the same names (`Stage` and `env`). [octopus](https://octopus.com/devops/jenkins/jenkins-build-parameters/)
- The shell script simply echoes them so you can see what was passed.

5. Click **Save** at the bottom.

***

## 5. Build once with env=Production

1. Open the `parameterized-job` main page.
2. Click **Build with Parameters** (left side).
3. In the **Stage** field:
   - Leave default `Build` or change if you want.
4. In the **env** dropdown:
   - Select `Production`.
5. Click **Build**.

After the build completes:

1. Click the build number (e.g. `#1`).
2. Click **Console Output**.

You should see something like:

```text
Stage parameter value: Build
env parameter value: Production
Finished: SUCCESS
```

This confirms the job is parameterized and correctly echoes the values, and it passes when `env=Production`.

***

## 6. Plugins and restart (if needed)

If Jenkins prompts about missing plugins (rare for a basic Freestyle job):

1. Go to **Manage Jenkins → Manage Plugins**.
2. Install required plugins under **Available**.
3. On completion, choose:

   - **Restart Jenkins when installation is complete and no jobs are running**.

4. Refresh the UI after Jenkins restarts if the page seems stuck.
