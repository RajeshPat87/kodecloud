Create a single Pod with the exact env vars, command, and restart policy. Since the command prints once and exits, `restartPolicy: Never` is correct and the output will be visible in logs. [github](https://github.com/joseeden/KodeKloud_Engineer_Labs/blob/main/Tasks_091-100/TASK_92_Print_Environment_Variables.md)

## YAML
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: print-envars-greeting
spec:
  restartPolicy: Never
  containers:
  - name: print-env-container
    image: bash
    env:
    - name: GREETING
      value: "Welcome to"
    - name: COMPANY
      value: "Nautilus"
    - name: GROUP
      value: "Datacenter"
    command: ["/bin/sh", "-c", "echo \"$(GREETING) $(COMPANY) $(GROUP)\""]
```

## Apply
```bash
kubectl apply -f print-envars-greeting.yaml
kubectl logs -f print-envars-greeting
```

## Notes
- The pod will usually go to `Completed` after printing the message once.
- `kubectl logs -f` will show the greeting output.
- The command must match exactly as requested. [github](https://github.com/joseeden/KodeKloud_Engineer_Labs/blob/main/Tasks_091-100/TASK_92_Print_Environment_Variables.md)
