## OTS — run on jump host as thor

```bash
#!/usr/bin/env bash
# jump host — inventory for all app servers + copy playbook
set -e

cd /home/thor/ansible

# 1. inventory: all three app servers under a group
cat > inventory <<'EOF'
[app_servers]
stapp01 ansible_host=stapp01 ansible_user=tony   ansible_ssh_pass=Ir0nM@n
stapp02 ansible_host=stapp02 ansible_user=steve  ansible_ssh_pass=Am3ric@
stapp03 ansible_host=stapp03 ansible_user=banner ansible_ssh_pass=BigGr33n

[app_servers:vars]
ansible_connection=ssh
EOF

# 2. cfg so sshpass isn't blocked by host-key checking; sets default inventory
cat > ansible.cfg <<'EOF'
[defaults]
host_key_checking = False
inventory = inventory
EOF

# 3. playbook: copy index.html to /opt/sysops on all app servers
cat > playbook.yml <<'EOF'
---
- name: Copy index.html to all app servers
  hosts: app_servers
  become: true
  tasks:
    - name: Ensure /opt/sysops exists
      ansible.builtin.file:
        path: /opt/sysops
        state: directory

    - name: Copy index.html to /opt/sysops
      ansible.builtin.copy:
        src: /usr/src/sysops/index.html
        dest: /opt/sysops/index.html
EOF

echo "== inventory =="; cat inventory
echo "== playbook.yml =="; cat playbook.yml
```

## Why each piece

**Inventory** — all three hosts under `[app_servers]`, each with its own user/password (they differ: tony/steve/banner). `[app_servers:vars]` sets `ansible_connection=ssh` once for the whole group instead of repeating it per line.

**ansible.cfg** — `host_key_checking = False` prevents the exact `sshpass ... Host Key checking is enabled` error you hit last time. Read automatically from the current dir, so validation works with no flags.

**Playbook** — `hosts: app_servers` runs on all three. `become: true` so the copy can write to `/opt/sysops` (root-owned by default). The `file: state: directory` task creates `/opt/sysops` if it doesn't exist (the copy would fail if the dir is missing). The `copy` module pushes the file from the jump host (`src`) to each server (`dest`).

## Watch-outs

- **`dest: /opt/sysops`** — the task says "placing it at `/opt/sysops`." Using `dest: /opt/sysops/index.html` puts the file *in* that directory (correct). If you write `dest: /opt/sysops/` (trailing slash) Ansible also treats it as a dir and keeps the filename — equivalent. Avoid `dest: /opt/sysops` with no trailing slash *if the dir doesn't exist*, or it creates a file literally named `sysops`. The explicit `/opt/sysops/index.html` + the mkdir task avoids all ambiguity.
- **`become: true` needed** — `/opt` is root-owned; without it the copy fails with permission denied. Password sudo works because the SSH user has sudo in these labs; if a `become` password were needed you'd add `ansible_become_pass`, but Nautilus app users don't require it.
- **`src` missing** → `/usr/src/sysops/index.html` must exist on the jump host (given). Confirm: `ls -l /usr/src/sysops/index.html`.
- **sshpass not installed** → `sudo yum install -y sshpass`.
- **Different passwords** — double-check each against the infra table; a wrong one fails only that host.
- Files exact: inventory `/home/thor/ansible/inventory`, playbook `/home/thor/ansible/playbook.yml`, dest dir `/opt/sysops`.
