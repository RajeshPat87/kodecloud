## OTS — run on jump host as thor

```bash
#!/usr/bin/env bash
# jump host — inventory + playbook to install httpd on all app servers
set -e

cd /home/thor/playbook

# 1. inventory: all three app servers under a group, with per-host user/pass
cat > inventory <<'EOF'
[app_servers]
stapp01 ansible_host=stapp01 ansible_user=tony   ansible_ssh_pass=Ir0nM@n
stapp02 ansible_host=stapp02 ansible_user=steve  ansible_ssh_pass=Am3ric@
stapp03 ansible_host=stapp03 ansible_user=banner ansible_ssh_pass=BigGr33n

[app_servers:vars]
ansible_connection=ssh
EOF

# 2. cfg so sshpass isn't blocked by host-key checking; sets default inventory
cat > ansible.cfg <<'EOF'
[defaults]
host_key_checking = False
inventory = inventory
EOF

# 3. playbook: install httpd using the yum module on all app servers
cat > playbook.yml <<'EOF'
---
- name: Install httpd on all app servers
  hosts: app_servers
  become: true
  tasks:
    - name: Install httpd package
      ansible.builtin.yum:
        name: httpd
        state: present
EOF

echo "== inventory =="; cat inventory
echo "== playbook.yml =="; cat playbook.yml
```

## Why each piece

**Inventory** — all three hosts in `[app_servers]`, each with its own user/password (they differ). `[app_servers:vars]` sets `ansible_connection=ssh` once for the group. Requirement 1 (all app servers) met.

**`yum` module** — the task explicitly says use the `yum` module, so `ansible.builtin.yum` (not `dnf` or `package`). `state: present` installs it if absent and is idempotent — reruns report "ok" not "changed", so validation passes on repeat.

**`become: true`** — installing packages is a root operation. Without it you get "You need to be root." The SSH users have sudo in these labs, so password-less sudo works.

**Uses password auth here** (not keys) — this task doesn't require password-less SSH, so embedding `ansible_ssh_pass` is fine and simplest. The `ansible.cfg` handles the host-key block that password auth otherwise trips on.
