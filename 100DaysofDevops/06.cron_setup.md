## 1. Complete One-Time Script (`ots.sh`)

Save this file on the **Jump Host** as `ots.sh`. It handles package installation, enables the daemon, updates `root`'s crontab safely using standard input streaming, and outputs execution validation for all target app servers.

```bash
#!/bin/bash
# ==============================================================================
# Script Name: ots.sh
# Purpose    : One-Time Deployment of cronie & sample root cron job
# Target DC  : Stratos DC (stapp01, stapp02, stapp03)
# ==============================================================================

# Application Server Credentials Matrix
declare -A SERVERS=(
    ["stapp01"]="tony:Ir0nM@n"
    ["stapp02"]="steve:Am3ric@"
    ["stapp03"]="banner:BigGr33n"
)

# Target Cron Schedule
CRON_LINE='*/5 * * * * echo hello > /tmp/cron_text'

echo "=================================================="
echo "Starting Automated Cron Setup across App Servers"
echo "=================================================="

# Ensure sshpass tool is available locally
if ! command -v sshpass &> /dev/null; then
    echo "[INFO] Installing sshpass on Jump Host..."
    sudo yum install -y sshpass &>/dev/null || sudo apt-get install -y sshpass &>/dev/null
fi

for HOST in "${!SERVERS[@]}"; do
    USER=$(echo "${SERVERS[$HOST]}" | cut -d':' -f1)
    PASS=$(echo "${SERVERS[$HOST]}" | cut -d':' -f2)

    echo "--------------------------------------------------"
    echo "Processing Target: $HOST ($USER)"
    echo "--------------------------------------------------"

    # Stream remote commands into SSH stdin to prevent local variable expansion issues
    sshpass -p "$PASS" ssh -o StrictHostKeyChecking=no "$USER@$HOST" "sudo -S bash" << EOF_REMOTE
$PASS
# 1. Install cronie
yum install -y cronie

# 2. Start and enable crond daemon
systemctl enable --now crond

# 3. Append cron entry to root user safely (idempotent setup)
(crontab -u root -l 2>/dev/null | grep -F '$CRON_LINE') || ( (crontab -u root -l 2>/dev/null; echo '$CRON_LINE') | crontab -u root - )

# 4. Show real-time verification details
echo -e "\n[STATUS] Cron Service on $HOST:"
systemctl is-active crond

echo "[SCHEDULE] Root Crontab on $HOST:"
crontab -u root -l
EOF_REMOTE

done

echo "=================================================="
echo "Deployment Complete across All Application Servers!"
echo "=================================================="

```
