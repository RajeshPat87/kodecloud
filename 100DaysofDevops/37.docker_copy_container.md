Use `docker cp` to copy the file **as-is** into the running container. `docker cp` preserves the file contents byte-for-byte, so it won’t modify the encrypted `.gpg` file. [spacelift](https://spacelift.io/blog/docker-cp)

## Command

```bash
docker cp /tmp/nautilus.txt.gpg ubuntu_latest:/home/
```

## Verify

```bash
docker exec ubuntu_latest ls -l /home/
```
