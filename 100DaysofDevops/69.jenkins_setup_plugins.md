## Plugin Installation Steps

### Step 1: Open the Plugin Manager

1. In Jenkins UI, on the left sidebar:

   - Click **Manage Jenkins**.
   - Click **Manage Plugins** (or **Plugins** in newer UI).

This opens the Jenkins **Plugin Manager / Update Center**. [cloudbees](https://www.cloudbees.com/blog/using-git-jenkins)

***

### Step 2: Install Git Plugin

1. In the Plugin Manager:

   - Go to the **Available plugins** tab.
   - Use the search field to type `Git`.

2. Locate the plugin named **Git plugin**:

   - Check the checkbox next to **Git plugin**.
   - Click **Install without restart** (or **Download now and install after restart**).

3. Jenkins will:

   - Download the Git plugin and its dependencies (git-client, SCM API, Credentials, etc.).
   - Show progress for each component.

If some dependencies initially show failures (e.g., Credentials, Plain Credentials, SSH Credentials, Credentials Binding), retry or allow Jenkins to restart as needed. [plugins.jenkins](https://plugins.jenkins.io/credentials/issues/)

***

### Step 3: Install GitLab Plugin

1. Still in the Plugin Manager:

   - On the **Available plugins** tab, search for `GitLab`.

2. Find **GitLab Plugin**:

   - Check the checkbox next to **GitLab Plugin**.
   - Click **Install without restart**.

3. Monitor installation:

   - Jenkins downloads GitLab Plugin and any dependencies.
   - The completion screen may suggest a restart.

***

### Step 4: Restart Jenkins (if prompted)

To finalize plugin installation:

- On the installation results page, if you see:

  > “Restart Jenkins when installation is complete and no jobs are running”

  click this option to perform a safe restart.

Or from the server (if you have terminal access):

```bash
service jenkins restart
service jenkins status
```

After restart, **wait until the Jenkins login page reappears** before further actions, as noted in the lab. [geeksforgeeks](https://www.geeksforgeeks.org/devops/how-to-solve-some-plugins-failed-to-install-properly-you-may-retry-installing-in-jenkins/)
