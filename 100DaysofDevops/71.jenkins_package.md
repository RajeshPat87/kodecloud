## Jenkins Job: install-packages

### 1. Access Jenkins UI

1. In the lab top bar, click **Jenkins**.
2. Log in with:
   - Username: `admin`
   - Password: `Adm!n321`.

You land on the Jenkins dashboard.

### 2. Create Freestyle Job

1. On the Jenkins dashboard, click **New Item**.
2. Name: `install-packages`.
3. Select **Freestyle project**.
4. Click **OK**.

This opens the job **Configure** page.

### 3. Add Parameter: PACKAGE

On the **Configure → General** section:

1. Enable **This project is parameterized**.
2. Click **Add Parameter → String Parameter**.
3. Set:
   - **Name**: `PACKAGE`
   - **Default Value**: `vim-enhanced` (optional).
   - **Description**: `Package name to install on storage server ststor01 (e.g. vim-enhanced)`.

Click **Save** to persist the parameter.

## SSH Setup: Jenkins → ststor01

To allow non-interactive Jenkins builds to SSH into the Storage Server, we configure SSH key-based authentication from `jenkins@jenkins` to `natasha@ststor01`.

### 1. SSH from Jump Host to Jenkins Server

On the **jump host** terminal:

```bash
ssh jenkins@jenkins
# password: j@rv!s
```

You are now on the **Jenkins server** as user `jenkins`.

### 2. Generate SSH Key on Jenkins Server

On Jenkins server (`jenkins@jenkins`):

```bash
ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa -N ""
```

- This creates `~/.ssh/id_rsa` (private key) and `~/.ssh/id_rsa.pub` (public key).
- No passphrase is set for non-interactive use.

### 3. Authorize Key on ststor01

Copy the public key to `natasha` on `ststor01`:

```bash
ssh-copy-id natasha@ststor01
# password: Bl@kW
```

If `ssh-copy-id` is not available, use:

```bash
cat ~/.ssh/id_rsa.pub
# copy the output line

ssh natasha@ststor01
# password: Bl@kW

mkdir -p ~/.ssh
echo "<copied public key line>" >> ~/.ssh/authorized_keys
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys

exit
```

### 4. Test Passwordless SSH

From Jenkins server, still as `jenkins`:

```bash
ssh natasha@ststor01
```

You should log in **without password prompts**. If this succeeds, Jenkins jobs can now SSH into `ststor01` non-interactively.

## Job Build Step: Execute shell

With SSH working, configure the job to install the package specified by `$PACKAGE` on `ststor01`.

### 1. Configure Build Step

In Jenkins UI:

1. Open `install-packages` job.
2. Click **Configure**.
3. Scroll to **Build Steps**.
4. Click **Add build step → Execute shell**.
5. Paste the following script:

```bash
#!/bin/bash

if [ -z "$PACKAGE" ]; then
  echo "PACKAGE parameter is not set"
  exit 1
fi

echo "Installing package '$PACKAGE' on storage server ststor01 from Jenkins server..."

# SSH from Jenkins server (user jenkins) to Storage Server (user natasha),
# and install the package using yum.
ssh natasha@ststor01 "sudo yum install -y $PACKAGE"

if [ $? -ne 0 ]; then
  echo "Package installation failed on ststor01"
  exit 1
fi

echo "Package '$PACKAGE' installed successfully on ststor01."
```

6. Click **Save**.

## Usage: Run With PACKAGE=vim-enhanced

### 1. Trigger a Build

1. Open the `install-packages` job.
2. Click **Build with Parameters**.
3. In the `PACKAGE` field, enter: `vim-enhanced`.
4. Click **Build**.

### 2. Check Console Output

After the build completes:

1. Click the new build number (e.g., `#1`).
2. Click **Console Output**.

Expected logs:

- “Installing package 'vim-enhanced' on storage server ststor01 from Jenkins server...”
- SSH connection line.
- `sudo yum install -y vim-enhanced` output (download/install or “already installed”).
- “Package 'vim-enhanced' installed successfully on ststor01.”
- Build result: **SUCCESS**.

### 3. Verify on Storage Server

From any terminal that can reach `ststor01`:

```bash
ssh natasha@ststor01
# password: Bl@kW (if key not used here)

rpm -q vim-enhanced
```

If `rpm -q vim-enhanced` outputs the package name, installation is successful.

## Reliability: Repeated Executions

To ensure reliability:

1. Run the job again with the same parameter:
   - `PACKAGE=vim-enhanced`.
2. Observe console output; it should succeed, possibly showing that the package is already installed.
3. Optionally, test with another package (e.g., `htop`) to confirm it can install arbitrary packages.

Consistency across runs demonstrates the job is stable and reusable.

***

## Plugins and Jenkins Restart

If any required plugins (e.g., SSH-related) are missing:

1. In Jenkins UI, go to **Manage Jenkins → Manage Plugins**.
2. Install needed plugins under **Available**.
3. On completion, choose:

   - **Restart Jenkins when installation is complete and no jobs are running**.

4. Wait for Jenkins to restart, then log back in as `admin` and confirm the job still works.
