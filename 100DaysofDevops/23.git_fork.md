If you want to do it **entirely from commands**, use the Gitea API and/or `git` commands, but you still need a valid URL and access to the Gitea server.

## If you have the repo URL already
```bash
git clone <original-repo-url>
cd story-blog
git remote rename origin upstream
git remote add origin <your-fork-url>
git push -u origin main
```

## If you want to fork via API
You can use `curl` against the Gitea API if you have credentials and the API URL:

```bash
curl -u jon:Jon_pass123 \
  -X POST \
  "http://<gitea-host>/api/v1/repos/sarah/story-blog/forks"
```

## If you need to work with the fork afterward
```bash
git clone <fork-url>
cd story-blog
git remote -v
git branch
git push
```
