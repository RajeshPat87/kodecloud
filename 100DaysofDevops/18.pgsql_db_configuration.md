Below is the complete **`ots.sh`**, **runbook**, and **Mermaid** for the MariaDB task.

## ots.sh
Run this on the Nautilus DB server as a user with sudo privileges.

```bash
#!/bin/bash
set -e

sudo yum install -y mariadb-server

sudo systemctl enable mariadb
sudo systemctl start mariadb

sudo mysql -e "CREATE DATABASE IF NOT EXISTS kodekloud_db9;"
sudo mysql -e "CREATE USER IF NOT EXISTS 'kodekloud_tim'@'localhost' IDENTIFIED BY 'TmPcZjtRQx';"
sudo mysql -e "GRANT ALL PRIVILEGES ON kodekloud_db9.* TO 'kodekloud_tim'@'localhost';"
sudo mysql -e "FLUSH PRIVILEGES;"
```

## Runbook
1. SSH into the Nautilus DB server.
2. Save the script above as `ots.sh` or run it inline.
3. Execute:
```bash
bash ots.sh
```
4. Verify MariaDB is running:
```bash
sudo systemctl status mariadb
```
5. Verify the database exists:
```bash
sudo mysql -e "SHOW DATABASES LIKE 'kodekloud_db9';"
```
6. Verify the user exists and privileges are granted:
```bash
sudo mysql -e "SHOW GRANTS FOR 'kodekloud_tim'@'localhost';"
```

## Mermaid
```mermaid
flowchart LR
    A[Login to Nautilus DB Server] --> B[Install MariaDB]
    B --> C[Enable and start mariadb]
    C --> D[Create database kodekloud_db9]
    D --> E[Create user kodekloud_tim with password]
    E --> F[Grant all privileges on kodekloud_db9]
    F --> G[Verify database and grants]
```
