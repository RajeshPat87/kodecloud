Use a Deployment running `grafana/grafana:latest` on port `3000`, then expose it with a NodePort Service on `32000`. Grafana’s login page should be reachable without any extra in-app configuration. [grafana](https://grafana.com/docs/grafana/latest/setup-grafana/installation/kubernetes/)

## YAML
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: grafana-deployment-devops
spec:
  replicas: 1
  selector:
    matchLabels:
      app: grafana-devops
  template:
    metadata:
      labels:
        app: grafana-devops
    spec:
      containers:
      - name: grafana-container
        image: grafana/grafana:latest
        ports:
        - containerPort: 3000
---
apiVersion: v1
kind: Service
metadata:
  name: grafana-service
spec:
  type: NodePort
  selector:
    app: grafana-devops
  ports:
  - protocol: TCP
    port: 3000
    targetPort: 3000
    nodePort: 32000
```

## Apply
```bash
kubectl apply -f grafana.yaml
kubectl get deployment grafana-deployment-devops
kubectl get svc grafana-service
kubectl get pods
```

## Access
Use the node IP with port `32000`:

```bash
curl http://10.244.226.179:32000
```

Or open the same URL in the browser to reach the Grafana login page. [chris-young](https://chris-young.net/58-100-deploy-grafana-on-kubernetes-cluster/)
