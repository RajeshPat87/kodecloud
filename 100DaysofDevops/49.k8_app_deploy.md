Use `kubectl create deployment` with the exact image tag `httpd:latest`. This creates a Deployment named `httpd` in the current namespace. [nbtechsupport.co](https://www.nbtechsupport.co.in/2022/02/create-httpd-deployment-in-kubernetes.html)

## Command
```bash
kubectl create deployment httpd --image=httpd:latest
```

## Verify
```bash
kubectl get deployments
kubectl get pods
```
