## 📜 One-Time Script (`setup_selinux.sh`)

This script installs the necessary SELinux packages and configures the `/etc/selinux/config` file to permanently disable SELinux upon the next system boot.

```bash
#!/bin/bash
# ==============================================================================
# Script Name: setup_selinux.sh
# Purpose    : Install SELinux packages & set SELinux state to disabled (permanently)
# Target Host: App Server 3 (stapp03)
# ==============================================================================

set -e # Exit immediately if a command exits with a non-zero status

echo "[1/3] Installing required SELinux packages..."
sudo yum install -y selinux-policy selinux-policy-targeted policycoreutils libselinux-utils

echo "[2/3] Configuring SELinux to be permanently disabled in /etc/selinux/config..."
if [ -f /etc/selinux/config ]; then
    # Backup original configuration
    sudo cp /etc/selinux/config /etc/selinux/config.bak
    
    # Update SELINUX directive to disabled
    sudo sed -i 's/^SELINUX=.*/SELINUX=disabled/' /etc/selinux/config
else
    echo "Creating /etc/selinux/config..."
    sudo mkdir -p /etc/selinux
    echo -e "SELINUX=disabled\nSELINUXTYPE=targeted" | sudo tee /etc/selinux/config > /dev/null
fi

echo "[3/3] Verification:"
echo "--- SELinux Configuration File (/etc/selinux/config) ---"
grep "^SELINUX=" /etc/selinux/config

echo -e "\n[SUCCESS] SELinux packages installed and persistent configuration set to disabled."
echo "[NOTE] A reboot is required to apply the change permanently (scheduled for tonight)."

```

SELinux (**Security-Enhanced Linux**) is a kernel-level security architecture designed to enforce access controls that restrict what processes and users can do on a Linux system.

Here is a breakdown of why these specific SELinux packages exist and what purpose they serve:

---

## 🛡️ Core Purpose of SELinux

By default, Linux uses **Discretionary Access Control (DAC)** (standard file permissions like `chmod` and `chown`). Under DAC, if a web server process (like Apache or Nginx) running as `root` or `www-data` is compromised via a vulnerability, the attacker gains full access to all files that user can reach.

SELinux adds a layer of **Mandatory Access Control (MAC)**:

* **Principle of Least Privilege:** Even if a process runs with root privileges, SELinux confines it to a strict sandbox (a "type" or "domain").
* **Damage Control:** If an attacker compromises an application, SELinux prevents them from reading unauthorized system files, opening arbitrary network ports, or executing malicious scripts elsewhere on the server.

---

## 📦 Purpose of the Installed Packages

When you install the standard SELinux suite on a RHEL/CentOS/Rocky Linux machine, each package serves a specific role:

| Package | Purpose & Function |
| --- | --- |
| **`selinux-policy`** | Provides the core framework and base definitions for SELinux security policy configurations on the system. |
| **`selinux-policy-targeted`** | The default, pre-configured policy for enterprise Linux. It targets and confines key public-facing system services/daemons (like HTTPD, SSH, MySQL) while leaving general user sessions unconfined. |
| **`policycoreutils`** | Contains essential management utilities (such as `semanage`, `restorecon`, `semodule`, `setfiles`, and `fixfiles`) required to manage, edit, and troubleshoot SELinux policies and contexts. |
| **`libselinux-utils`** | Provides basic command-line binaries (like `getenforce`, `setenforce`, and `selinuxenabled`) used to check or alter the operational state of SELinux. |

---

## ⚙️ How SELinux States Work

SELinux operates in one of three modes:

1. **Enforcing:** Policies are strictly applied; unauthorized access attempts are blocked and logged.
2. **Permissive:** Policies are not strictly enforced (access is allowed), but violations are logged for auditing/debugging.
3. **Disabled:** SELinux features are completely turned off in the kernel (which is what your current requirement sets for post-reboot).
