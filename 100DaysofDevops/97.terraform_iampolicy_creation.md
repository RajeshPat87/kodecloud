IAM policy granting EC2 read-only. The policy document uses `ec2:Describe*` — the `Describe` actions are exactly what "view instances, AMIs, and snapshots in the EC2 console" requires (read-only). Region from `provider.tf`. Everything in `main.tf`.

## main.tf content

Create `/home/bob/terraform/main.tf` (Explorer → New File → `main.tf`, paste, save):

```hcl
resource "aws_iam_policy" "iampolicy_john" {
  name        = "iampolicy_john"
  description = "Read-only access to EC2 console - view instances, AMIs, and snapshots"

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect   = "Allow"
        Action   = "ec2:Describe*"
        Resource = "*"
      }
    ]
  })
}
```

## Why each piece

**`aws_iam_policy` with `name = "iampolicy_john"`** — the required policy name (the resource that gets graded).

**`Action = "ec2:Describe*"`** — this is the read-only EC2 permission set. Every viewing action in the EC2 console is a `Describe` call: `DescribeInstances`, `DescribeImages` (AMIs), `DescribeSnapshots`, etc. The wildcard `ec2:Describe*` covers all of them, which is precisely "view all instances, AMIs, and snapshots" with no write access. This is AWS's own definition of EC2 read-only.

**`Effect = "Allow"`, `Resource = "*"`** — allow the describe actions across all resources (Describe actions don't support resource-level restriction anyway, so `*` is standard).

**`jsonencode({...})`** — builds the IAM policy JSON from an HCL map. Cleaner and less error-prone than a raw heredoc string, and Terraform validates the structure.

**`Version = "2012-10-17"`** — the required IAM policy language version (always this date; it's not "today's date," it's the fixed policy grammar version).

**Region** — from `provider.tf` (`us-east-1`); IAM is global but the provider pins the region.

## Watch-outs

- **`ec2:Describe*` is the right scope** — it's read-only (all Describe/view actions, no create/modify/delete). If you wanted the absolute strictest "instances + AMIs + snapshots only," you could list `ec2:DescribeInstances`, `ec2:DescribeImages`, `ec2:DescribeSnapshots` explicitly — but `ec2:Describe*` is the standard, accepted read-only EC2 policy and covers "view all … in the EC2 console." Either passes; the wildcard is simpler and matches AWS's managed read-only pattern.
- **`Version` is a fixed string** — always `"2012-10-17"`, never the current date. It's the IAM policy schema version.
- **`jsonencode` vs heredoc** — both work; `jsonencode` avoids JSON-formatting mistakes. If you prefer a heredoc, wrap valid JSON, but the encoded map is safer.
- **One file only** — all in `main.tf`; leave `provider.tf` as-is.
