Use these commands on **App Server 1**:

```bash
docker pull busybox:musl
docker tag busybox:musl busybox:media
```

## Verify
```bash
docker images | grep busybox
```

You should see both `busybox:musl` and `busybox:media` pointing to the same image ID. [nbtechsupport.co](https://www.nbtechsupport.co.in/2021/03/pull-docker-image.html)
