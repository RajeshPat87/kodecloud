Use this command on **App Server 3** to create the bridge network with the required subnet and IP range: [docs.docker](https://docs.docker.com/reference/cli/docker/network/create/)

```bash
docker network create -d bridge --subnet 192.168.30.0/24 --ip-range 192.168.30.0/24 beta
```

## Verify
```bash
docker network inspect beta
```

This will show the `beta` network using the `bridge` driver with the specified IPAM settings. [docs.docker](https://docs.docker.com/reference/cli/docker/network/create/)
