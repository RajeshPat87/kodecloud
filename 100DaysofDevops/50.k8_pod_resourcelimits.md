Use a Pod manifest with the exact resource requests and limits, then apply it with `kubectl`. The key is to set the container name, image tag, and resources exactly as specified. [kodekloud](https://kodekloud.com/community/t/kubernetes-level1-practice-limits-requests-resources-marked-wrong/342315)

## Pod YAML
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: httpd-pod
spec:
  containers:
    - name: httpd-container
      image: httpd:latest
      resources:
        requests:
          memory: "15Mi"
          cpu: "100m"
        limits:
          memory: "20Mi"
          cpu: "100m"
```

## Apply it
```bash
kubectl apply -f httpd-pod.yaml
kubectl get pod httpd-pod
```

## Verify
If needed, confirm the resources were applied with:
```bash
kubectl describe pod httpd-pod
```
